# 故事板执行映射｜填写模板

> 复制到项目目录后填写。审片板只给人看时可省略“实际视频参考节点”；决定交给视频模型时必须填真实节点和输入顺序。`CUT`、`MOVE`、`STATE` 分别表示真正切镜、同镜运动阶段、仅供理解的状态图。

## 镜段与来源

- 集／场／镜段：
- 剧本事件与原文台词范围：
- 当前采用的人物多视图、场景、色卡及道具节点：
- 故事板版本／页号；是否经过人数、道具、接触和轴线核验：
- 实际视频参考节点与输入顺序（若使用）：
- 当前模型／模式／画幅／画质／生成数量：
- 有效剧情窗口；总生成时长；预计选用区间；首尾可裁余量：
- 本段观众进入时知道什么；离开时新增什么：

## 镜尾和下一段入口

- 镜尾人物、道具、视线、运动方向、景别、光向和声场：
- 下一段首帧／首声如何接住；转场载体与切点：
- 相邻镜号有意保持相近景别或越轴的依据（无则写无）：

## 提交和回片核对

- 提交前：实际绑定的故事板、站位图和身份／场景／色卡节点与提示词所指一致；黑白纸面不进入彩色成片。
- 计费：本次网页报价、模型、时长、画质、数量、优惠开关和证据时间；任务 ID 与最终扣费分别记录。
- 回片：按正常速度播放并逐格记实际起止、摄影路径／落幅、可见人数与道具、台词及声音交接、问题片段的时间码。
- 剪辑：实际画面入出点与声音入出点分别列出；删掉重复揭示／空等前后时长；保住因果、接触和完整字音。
- 结论：可用／局部可剪／需返修／尚未审；候选版本和用户正式采用分别记录。
