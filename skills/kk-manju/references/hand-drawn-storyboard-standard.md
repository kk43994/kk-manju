# 黑白手绘张力故事板规范

用户于 2026-11-10 明确选定《别惹大师兄》EP003 S24A 叶宇御剑页的表现方式，作为今后给人审看的故事板默认样式。这里约束的是**审片故事板**；视频成片仍由项目人物、场景、色卡和 STYLE LOCK 决定画风。技术站位图可以另做，不能代替有导演设计的审片页。

## 一页的视觉语言

- 黑白铅笔与墨线的电影动作速写：保留人物体积、脸或手的表演、服装关键纹样和道具辨识；线条可以有手绘试探感，不追求抛光的游戏 CG 灰度截图。
- 分格大小与形状服从戏剧强弱：小格聚焦动作触发，大格承载接触、情绪或结果；可用斜切边界、留白、局部越格、方向一致的速度线、交叉排线和强透视。分格不能遮住关键脚手接触或让地理关系失真。
- **相邻小分镜必须设计明显的景别/关注点跳变**。先给每格指定唯一主要关注点，再安排尺度起伏，例如「手势极近景 → 飞剑运动中远景 → 鞋底接触极近景 → 人与环境中全景」。相邻若连续保持近似景别，导演稿须说明是同镜运动阶段、动作匹配或故意延迟揭示；不能只是生图模型重复了构图。
- 景别变化同时改变观看问题：谁触发 → 物怎样动 → 是否真正接触/受力 → 对空间与人物造成什么结果。速度线只强化已确定方向，不掩盖方向错误。
- 单页只放足以读懂的一组动作；一页不够就两页或更多页。默认每页约 3–5 个有职能的格子，按内容决定，**不再为省生图次数强制九宫格或凑满格子**。复杂动作优先按单人、单物、简单场景拆页，最后用关系镜合流。

## 先做技术核验，再做张力页

脚踩飞剑、递物、攻防接触、多人交错等动作，先用简单背景的单张关键状态图核对人数、物件数量、朝向、实际接触、支撑、受力、机位工作侧。若这一步不成立，不能把错误状态扩成漂亮分镜。通过后再用手绘张力页组织景别与注意力；任何一格画错物理或左右关系，保留为失败候选，不作为后续视频模型的参考。

## 复杂镜头作为视频实际参考

当用户要求把故事板一起交给视频模型，或复杂动作单靠文字容易丢失因果时，先核验该板的角色数、物件数、归属、接触、受力和屏幕方向。将**通过核验的每一页**上传为当前项目真实图片节点，取得上传及节点回执；提交视频时把节点加入参考列表，并在提示词中以实际节点 ID 逐页注明职责。没有完成真实绑定，不能称故事板已作为模型参考。失败旧板只留历史，不混进参考。

把页内格子编译成视频的观看顺序：每一格对应注意焦点、景别、摄影机位置、动作起终状态；多页则写明跨页接力。一个短视频容器可挑关键格与合并同阶段动作，不要求机械平均分配格子时长，但必须保留“触发→运动→接触/受力→结果”的因果和用户认可的景别跳变。人物多视图仍管身份，场景图仍管地理，色卡仍管色彩；故事板只管镜头设计。黑白线稿不能把彩色成片变成分格漫画，也不能让同页多次画出的同一角色/道具复制成多个实体。提交后回读视频节点的实际图片输入和转换后的提示词，确认每一页都已进入任务。

四人及以上同框仍须按[站位锚定规范](blocking-transition-standard.md#多人复杂站位的执行锚)先定每人的唯一身份和位置。故事板可用近景、画外人物和多页拆解来降低单格复杂度，但不能把原剧本的角色关系剪没。每格及每页记录画内人数、画外声源、镜头起终状态与衔接。

实际转视频时按[故事板到视频的摄影执行与节奏](storyboard-execution-and-pacing.md)给每格建立摄影起点、动作触发、移动路径与速度、焦点、落幅、切点、声音和时间窗。纸上分格不自动等于成片切镜；同镜运动阶段须在正文中连续执行。回片若始终停留在一个大全景，即使人物动作大致发生，也不能算故事板镜头设计已执行。

## 提示词骨架

```text
用途：给人审看的黑白手绘电影故事板，不是视频最终画风或首帧。
参考职责：人物多视图只锁身份/服装；场景母图只锁地理；道具图只锁归属与形状；已认可手绘页只锁线条、分格节奏和视觉张力，不复制其人物/剧情。
本页剧情动作与镜头范围：〔镜号，开始状态→结束状态〕。
人数/道具边界：〔每格谁入画、画外谁在场、各自物件与手〕。
分格设计：〔格1 关注点+景别+角度〕→〔格2 完全不同的关注点+景别〕→……。分格大小依戏剧强弱变化，允许斜切、速度线与强透视；运动方向一致。
画面验收：〔接触、受力、方向、画面左右、是否复制人物/物件〕。无无关文字、姓名牌或成片字幕。
```

把提示词写成当前场景可直接执行的具体动作，不能只把骨架中的名词原样提交。生成后遮住说明文字验图；画风好但镜号、人数、接触或朝向错，仍退回。
