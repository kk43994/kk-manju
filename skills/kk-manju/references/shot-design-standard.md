# 镜头设计通用规范 V1

日期：2026-11-04
状态：用户确认纳入 KK独家漫剧的通用规范。用于故事片、短剧、漫剧、动画及其他叙事影像的导演与分镜设计。

本规范负责决定镜头。视频提示词的组织和模型执行说明见[02-视频提示词规范-V1](video-prompt-standard.md)。具体人物、题材、情节、画幅、片长、画风和供应商属于项目配置，不在本规范中固定。

## 一、镜头设计的核心

每镜建立一条有因果的设计链：

**戏剧任务 → 观看立场与观众感受 → 必须看见的信息或反应 → 人物调度 → 景别、机位、构图和运镜 → 切点 → 下一镜的承接。**

镜头可以推动情节、揭示信息、建立空间、组织动作、呈现关系或承托情绪。每镜选择一个主要职责，允许兼有次要职责。过渡、环境、动作细节镜也有价值，不必给每镜都制造强烈情绪转折。

“这一镜表达什么，所以这样拍”需要具体到可判断：

- 观众从哪里获得信息，知道得比角色多、少还是一样？
- 观众此刻与谁更接近？观察、认同、怀疑、等待还是疏离？

- 到镜尾，观众对事件、人物或关系有什么新的理解？
- 哪个可见变化承担这次理解：距离、眼神、遮挡、姿态、物件、空间或行动结果？

“高级、紧张、感人、电影感”不能单独成为镜头职责；需要说清紧张来自什么、观众等待什么、什么变化会改变预期。

## 二、先设计整场，再设计单镜

### 2.1 场次设计

每场先确定：

1. 剧情依据与版本：已经确认的事实、对白，以及本次允许调整的范围。
2. 场次目标：人物要什么、阻碍是什么、关系或认知在哪里改变。

3. 节拍顺序：信息出现、人物处理、行动、对方反应、结果。仅在有变化处划分节拍。
4. 观众体验：从什么状态进入，到什么状态离开；中间何处积累、爆发、停住或释放。

5. 空间与调度：人物、关键物件、出入口、行动通路及摄影机可用工作侧。
6. 覆盖方案：哪些必须同镜看清，哪些适合切到听者、物件、关系或结果。

7. 声音与节奏：按[声音设计规范](sound-directing-standard.md)决定对白、环境、动作声、画外信息与静默的进入、持续、退出，以及人物/摄影回应，不能到提示词末尾才补音效。
8. 出入接口：按[衔接技巧库](shot-handoff-techniques.md)决定前镜交出什么、什么触发交接、后镜接住并新增什么；主动选用信息、声源、动作/尺度、声场与实体遮挡等接力。

关键场次若需重选整体拍法，先按[场次拍法选择与设计复核](scene-shooting-strategies.md)比较观看体验、揭示次序与注意力交接；普通连接段与已采用方案的局部返修沿现有设计推进。场次方案形成后，依[案例规范中的自动路线选择](case-based-camera-design.md)按当前模型容易出错的动作与空间关系分流：简单镜段用文字导演，复杂局部先故事板；简记理由并继续，不默认每段都画板或每段都询问用户。

完整段落的镜头先形成连贯序列，再划分制作任务。镜头、动作节拍、生成片段是不同单位；一次生成可以包含多个镜头，同一个镜头也可能有多个表演节拍。

### 2.2 信息与情绪的次序

- 先让观众具备理解所需的信息，再安排依赖该信息的反应。
- 信息可以故意隐藏，但要知道藏了什么、何时揭示、观众为什么继续看。

- 说话者不必一直占画面；关键内容可以落在听者脸上，让反应与话语同时发生。
- 情绪会跨镜累积。下一镜的演员反应继承此前已知事实、身体状态与关系变化。

- 紧张可以来自未知、逼近、时间压力、失去选择或双方目标冲突。剪得快只是其中一种表现方式。
- 情感段落通过关系和行动推进。何处等待、停多久，由表演和信息决定。

## 三、表达意图如何转成摄影选择

### 3.1 景别、机位和构图先回答“让观众看什么”

| 设计维度 | 需要作出的判断 |
|---|---|
| 景别 | 此刻优先看环境、人与人的关系、完整动作、表情还是物件细节？前镜已经交代的空间，本镜是否仍需重复？ |
| 观看位置 | 观众站在谁的观察位置？是客观观察、越肩关系还是角色主观视点？ |
| 高度与角度 | 角度来自人物真实位置、视线还是有意的心理组织？与前镜的高低关系能否对应？ |
| 镜头透视 | 需要怎样的距离感和纵深关系？焦段服务这个目的，不用一串数字代替构图。 |
| 前后景与遮挡 | 哪一层先被注意？遮挡是在制造受限感、隐藏信息，还是无意挡住必要动作？ |
| 画面位置与留白 | 人物朝向、视线空间、负空间和边缘压力怎样改变关系感受？ |
| 焦点与景深 | 本镜只有一个主要注意对象，还是需要同时读清两人的反应或接触过程？ |
| 光与色 | 光源方向、明暗、色彩与材质怎样支持场次气氛，并延续相邻镜头？ |
| 持续时间 | 观众需要多久看懂、等待、感受变化？信息读完以后是否还有新的表演？ |

俯仰角、焦段、色彩和构图没有固定的情绪译码。同一种手法在不同情境中可能产生不同效果，必须联系人物处境、前后镜头和声音判断。

### 3.2 运镜的选择理由

以下是选择思路，不是“某种情绪必须配某种运镜”的规定。

| 这一镜的表达任务 | 可以考虑的手法 | 具体怎样起作用 | 设计时必须交代 |
|---|---|---|---|
| 将注意从事件收进人物，捕捉认知发生变化 | 推近 push-in / dolly-in | 环境逐渐退出注意，表情或关键细节在画面中变得更重要 | 什么变化触发推近；起始和结束景别；在何种反应上停住 |
| 从个人反应扩大到环境、群体或后果 | 拉远 pull-back / dolly-out | 逐步揭示原来不知道的空间与关系，也可能形成疏离或失控感 | 拉开后新增什么信息；主体在整体中的位置怎样改变 |
| 将注意从一个对象交给另一个对象 | 摇镜 pan / tilt | 摄影机原地转向，沿视线、声源或动作揭示另一端 | 谁触发转向；水平或俯仰方向；途中是否有叙事信息；终点是谁 |
| 改变观看位置，利用前后景揭示关系 | 移镜 lateral move / truck | 摄影机平移产生视差，遮挡物和人物关系逐渐改变 | 路径与遮挡；主体是否同时移动；新揭示的关系；轴线怎样保持 |
| 让观众与人物一起经历行动 | 跟拍 tracking / follow | 保持与行动者的距离或有意追上、落后，形成参与感和压力 | 跟谁；前、后或侧面；速度变化；何时脱离或停住 |
| 扩大空间尺度，或从整体落到个体 | 升降 crane / pedestal | 通过摄影机高度变化组织纵深、尺度和人物处境 | 是摄影机升降还是镜头俯仰；沿途看见什么；最终尺度 |
| 随关系变化重新揭示双方 | 环绕 orbit / arc | 连续改变人物前后关系和背景，可能强化亲密、审视或失衡 | 弧线范围、观看对象、速度及每段新增信息；跨轴如何让观众理解 |
| 让观众等待人物行为，感受距离与停顿 | 固定 locked-off | 机位不动，演员进入、接近、退出或沉默成为画面变化 | 固定画面里什么在变化；观众等待哪个结果；结束点 |
| 把注意从同框的一项信息交给另一项 | 移焦 rack focus | 摄影机位置可以不变，通过清晰度转移组织发现 | 两个焦点对象、转移触发及完成后停留；景深能否同时完成动作任务 |

变焦 zoom 改变焦距；推拉是摄影机前后移动。二者带来的透视和空间感不同，设计时分别标明。手持、稳定器、轨道是运动质感或执行选择，也需要服务场次，而非作为情绪的自动替代物。

### 3.3 每次移动都写完整

**起始构图 → 触发 → 方向与路径 → 速度与幅度 → 跟随/注视对象 → 结束构图 → 停住的理由。**

例：
> 角色听到关键名字后停止整理文件。摄影机此时从侧前方中近景沿短直线推近，保持眼睛为注意中心，收至近景，在她重新望向对方时停住。目的是让观众发现她正在掩饰反应，暂不揭示她的真实动机。

速度应可感知：克制缓进、短促跟随、急速转向后停住等。具体距离或角度只有在帮助复现时才填写；避免没有依据的厘米和帧级精度。

关键段落需要空间揭示、节奏升级、群体关系或强烈观看体验时，主动设计有收益的组合运镜，不能所有方案都退回固定、慢推和小幅横移。可将荷兰角（画面倾斜）、环绕（观察方向/路径）和上升（高度）协同，也可用弧线推近与移焦、侧跟与遮挡揭示等组合；分别交代启动、方向、速度、主要注意对象、沿途新信息与终点。具体方法与用户认可案例见[案例导演思路与组合运镜](case-based-camera-design.md)。

组合运镜按叙事任务选择，不要求每镜都同时推、摇、升降和环绕。用户已选的组合须保留其力度和分量，不在编译阶段因复杂而简化；实际问题定位后再作有依据的局部调整。

## 四、人物表演与摄影是同一项设计

### 4.1 表演链

**刺激 → 处理信息 → 可见反应 → 行动或决定 → 对方反应。**

每镜写清：

- 角色此刻要达到什么，受到什么阻碍；
- 起始姿态、视线、身体重心与关键持物；

- 语言与动作是同时、先后还是打断关系；
- 可被拍到的变化，如一句话后停手、目光避开、距离缩短；

- 镜尾留下的身体状态与心理状态。

内心变化通过行为呈现。可以有克制、停顿、迟疑，不强制每个情绪都用瞪眼、落泪或夸张表情。

### 4.1.1 从具体动作设计观众的注意

- 先找这个人物在该处境下会做的具体行为：闲适时的习惯、被刺激后的反应、急于完成的事，以及行动发生的小意外。不能因为写了“手指松开、看掌心、轻微一动”就认定情绪已经成立；动作要有眼前原因，幅度也要与情绪相称。
- 每个节拍连写“人物做什么 → 观众此刻必须看哪里 → 摄影机如何靠近、跟随、转移或停住 → 动作结果及下一个反应”。站位、手别和道具尺度是执行底线，还须有真正的观看设计。
- 情绪力度服从剧情与用户要求。重大异常可以用鲜明震惊、快速推近和眉眼特写；不能默认改成微弱眼神变化。也不能把所有反应都升级成夸张表情，前后强弱要有变化。
- 细节特写选择有叙事作用的时刻，如物件离手、接触失稳、补接完成、眼神认出异常；不把每根手指和每一步都切成同等重要的特写。关键因果需要连贯观看时，可以用跟随物件或人物的连续长镜头，让焦点随事件变化。
- 采用子弹时间或局部速度变化时，写清正常速度的起势、变速时刻、变速中摄影机的运动、恢复正常速度的触发及随后结果。时长服务观看重点，不默认长时间悬停；对白音高与语速是否保持正常须单独说明。
- 道具表演可以有意外和补救来体现性格，但必须拍清来处、离手轨迹、接触、失稳原因、补救和最终持有状态。复杂动作先按关键状态检查空间与受力；故事板用于验证这些状态，不自动决定成片要切多少镜。
- 同一个性格动作可以在情绪变化后产生新的意义，例如由随意把玩到烦躁丢开；具体动作属于项目，不把某种道具或行为固化为所有剧本的套路。取出、丢弃或转交后同步后镜状态，不能无故重新出现。

### 4.2 动作因果

复杂动作先以文字、草图或预演说明关键姿态：
**准备 → 接触 → 施力/受力 → 位移 → 释放 → 恢复。**

需要观众理解的接触和结果，应有可读的空间、支撑与受力方向。是否同镜拍完、何处可以动作匹配剪接，由该动作的叙事任务决定。故事板是设计工具，不自动等于要生成并挂载一张图片。

### 4.2.1 动作故事板的可视化执行

- 先区分用途：审片故事板给用户与导演看故事、镜头、表演和衔接，可以覆盖整集；执行参考板只在后续模型需要时实际接入。审片已通过不自动意味着必须把板喂给视频。用户选择黑白时用黑白人物速写保留体积、表情与灰阶辨识；人物动作与摄影机箭头用实线/虚线或简短文字区分，遵守黑白要求，不强制红蓝上色。
- 需要动作预演时，先画可供拍摄的关键画面。当前首选黑白铅笔人物速写：保留身体体积、重心、衣褶、接触和必要表情；不要自动简化成火柴人，也不要做成精美但机位重复的角色展示板。绘图模型采用项目指定的 Image 等实际入口。
- 每格由画面承担叙事，配套文字补充镜号、动作阶段和摄影执行。黑白审片页优先不把箭头、字卡画进画面；如确需技术标记，在页边用不同线型区分人物/道具与摄影机路线，光向另注。彩色工作图可用红/蓝分流，但颜色、箭头和术语不能替代画面里正确的因果与空间。
- 用户认可的审片故事板样式以[黑白手绘张力故事板规范](hand-drawn-storyboard-standard.md)为准：不等分格、斜切留白、黑白墨线、强透视与有方向的速度线。先完成镜头设计，再按关注点与戏剧强弱分配格子；同一连续镜头使用S01-A/B/C等阶段编号，真实切镜才标CUT。旧九宫格仍可用于简单汇总，但不再是默认或必须凑齐的版式。
- **相邻小分镜要有明确的景别尺度跳变与关注点交接**：关系与方位→动作细节/物件→实际接触/结果→人物及环境反应。前格提出的观看问题由下一格接住；不连续给出同尺寸、同机位的人物展示。若需要相近景别保留连续运动，写出同镜阶段或动作匹配的理由。
- 一页不足以容纳清楚的起幅、路径与落幅时，继续出第二页或更多页；不为压缩张数混入过多人物、物件或背景。每页标注简短，完整运镜与声音放配套正文。技术关键先用少人少物的单张状态图验证，再扩成张力故事板；漂亮但接触、方向或身份错的图不能放行。
- 跟随投掷物时先在俯视图固定抛出端、接收端、摄影机位置与朝向。镜头从投出者附近沿物件前进并看向接收者时，前景是物件、中后景是朝来物接应的接收者；投出者位于机后时应退出画面。不能一面标追向接收者，一面画投出者背影在前方；侧跟或绕拍必须说明改变朝向的连续路径。
- 验收必须遮住文字再看图：方向、人物相对位置、道具归属、重心离开支撑、接触和恢复能否独立读懂。逐格核对箭头和实际画面是否一致；文字写对但画反、追物变递物、两手变多手、道具尺度漂移、树干左右跳变，均退回，不挂作已采用的视频参考。
- 故事板输入视频时仅承担摄影、动作和节拍职责；人物母版、场景母版、色卡仍控制身份与最终画风，分格、箭头和铅笔笔触不能进入成片。未通过预演板不解锁依赖它的动作视频；可以继续制作不依赖该板的镜段。

镜头板审过后，按[故事板到视频的摄影执行与节奏](storyboard-execution-and-pacing.md)将每格的观看任务、摄影触发/路径/落点、真实切镜或同镜阶段、声音和时间窗写成执行表，再编译视频提示词。分镜的大胆景别变化不能在提示词阶段被简化为单一大全景。总时长以剧本节拍和可并行的声画事件估计，不把模型最长时长当作每镜目标。

### 4.3 对白与时间

- 保留当前认可剧本的说话人、句意、次序及逐字台词；改写需求回到剧本层处理。
- 标明画内对白、画外对白、旁白或内心独白；口型需求随声音性质确定。

- 表演、走位、反应可以与对白重叠，不按“说完一句—空等—再动作”排时间。
- 纸面估时用于预算；对白实际速度、停顿、呼吸与动作容量需要试听或排练验证。

- 反应镜可以承接上一镜未说完的声音，避免长台词把画面锁在说话者身上。
- 台词结合说话对象、现场认知和情绪写成自然叙述，保留必要称呼、句意与转折。短句、完整长句和停顿各有语境，不机械删成碎句，也不为“有人味”统一加语气词。用户逐字确认的句子保留；改动长度后重新安排声音与动作，不靠加速念白挤进旧时槽。

## 五、切镜是设计的一部分

整集文字俯视图、调度起终状态及跨视频转场动画按[文字站位与转场动画规范](blocking-transition-standard.md)设计。每个跨片接口除状态承接，还写动画起势→交界画面/切点→后段揭示、方向、可见时长及模型/后期归属；不要把声音桥单独当作已完成视觉动画。

每个切点至少回答：

1. 为什么在这里离开当前画面？
2. 下一镜提供什么新信息、情绪视角、关系或动作结果？

3. 用什么把两镜连起来：视线、动作、声音、构图、因果或有意反差？
4. 哪些状态延续，哪些是被明确设计的时间/空间跳变？

可采用动作匹配、视线匹配、正反打、反应镜、物件插入、声音桥或有意跳切。不同做法服务不同目的，不强制每次切镜都需要转场特效。

换景别、换机位时，连续性并不要求两幅画面相同；要求空间、行为、信息和情绪之间的关系可理解。有意失序、越轴或跳切应记录表达目的与观众重新定位的依据。

需要跨生成片段组接时，在设计卡增加后期接口：承接的动作/视线/声音、允许省略的过程、不可丢的关键因果、所需覆盖与运动余量。区分生成应拍到的连续动作与计划后期制作的效果；余量用于选择切点，不计成额外剧情停顿。实际素材到位后按[剪辑规范](post-production-standard.md)核对可用区间与切口，不能只凭计划尾态宣布接得上。

## 六、连续性检查

| 层面 | 前镜终点与后镜起点需要核对的内容 |
|---|---|
| 地理 | 人物相对地标的位置；机位改变后实际能看到哪一面；通路与出入口 |
| 方向 | 工作侧、视线互补、进出画方向、人物真实朝向 |
| 身体 | 站、坐、卧、跪，身体支撑，动作进度与速度 |
| 道具 | 所有权、持物手、取放位置、数量、使用后的状态 |
| 外观 | 身份、衣装、发型、湿度、伤情、污损及其发生时间 |
| 光色 | 主光方向、光源变化原因、肤色、反差与场次色彩逻辑 |
| 声音 | 句子有没有重复或断裂，空间底声、音色、混响及音乐进出 |
| 信息与情绪 | 人物已知道什么；反应是否承接；关系是否改变 |
| 时间层 | 现在、过去、想象、梦境等是否清楚；哪些状态不能跨层继承 |

对剪辑中有意省略的动作，不要求把每个细节拍一遍；需要保证省略后结果自然、可推知，不破坏关键因果。重要物件的出现、危险动作的结果或叙事证据通常需要更明确的呈现。

## 七、通用镜头设计卡

每镜采用同一骨架，内容详略按复杂度调整：

- **镜号 / 场次 / 预计剪辑时长：**
- **剧情依据与镜头职责：**

- **观看立场与观众变化：** 镜头进入时 → 镜头结束时。
- **主要注意对象：** 观众必须看清什么。

- **摄影选择与理由：** 景别、机位、高度、构图、透视、焦点；分别如何服务职责。
- **运镜设计：** 固定或移动；起点 → 触发 → 路径/速度 → 终点；为什么选择这种手法。

- **人物与调度：** 起始状态 → 刺激与动作/反应 → 结束状态；涉及接触与持物时具体到手。
- **对白与声音：** 原文、说话人、发声方式、并行动作、环境及声音桥。

- **切点与后镜：** 切换理由、承接元素、下一镜新增信息。
- **连续性与视觉依据：** 必须保持的事实、需要看清的空间或状态；素材需求先记职责，具体绑定在执行阶段处理。

其中“理由”供创作判断与复盘使用。进入视频提示词时，摄影与表演指令必须完整保留，论证过程按需要精简。

## 八、通用示例：听到关键信息，却试图掩饰

这是虚构的方法示例，不属于任何项目剧本。

- **镜头职责：** 让观众发现听者并不平静，暂不解释她为什么隐瞒。
- **观众变化：** 以为普通交谈 → 注意到听者异常 → 想知道她隐瞒什么。

- **摄影选择：** 侧前方中近景保留脸和整理文件的右手；背景提供交谈关系，清晰度让位给主要反应。
- **运镜与理由：** 对方在画外说到一个名字时，她右手停住；此时短直线推近到近景，使注意由手上事务转到表情；她重新看向对方时停机。反应触发移动，推近完成后留出压住表情的瞬间。

- **表演：** 起初整理文件，听见名字后停手，呼吸短停，视线抬起，努力恢复原先表情。文件仍在桌上，右手仍搭着文件，左手位置不变。
- **对白与声音：** 画外原句来自项目剧本，连续说完；镜内角色无新增台词。示例不编造具体名字或句子。

- **切点：** 她重新看向对方时切对方反应，以互补视线连接，声音可跨切点延续。
- **边界：** 起始空间已经在前镜建立；此镜无需另拍房间全景，也不预先拍出尚未揭示的秘密。

## 九、设计自审

按作品效果审查：

- 信息与关系有没有被拍清，重要反应有没有可见的时间？
- 每次运动或停住是否有职责，景别和切换是否有变化依据？

- 表演、摄影、声音有没有争抢注意，或相互重复？
- 连续性是否帮助观众理解，跳变是否有意且可读？

- 节奏来自推进了多少内容，是否出现重复动作、无作用的等待或为了时长拖慢？
- 项目风格是否统一，同时允许转折时发生有意义的变化？

设计稿完成与成片有效分开记录。文字可以检查意图、覆盖、空间及时间预算；运动力量、表演自然度和真实观感仍要看素材。
