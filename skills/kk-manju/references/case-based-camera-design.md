# 从成熟案例学习导演思路、组合运镜与提示词写法

## 使用立场

用户提供并认可实际效果的案例时，先研究其有效设计与写法，继而迁移到当前剧本。不能把学习变成文字挑错，也不能仅凭运镜复杂、描述很细便推断不可执行。用户认可的效果属于用户反馈；未取得视频时如实说明只能直接分析提示词与资产图，设计意图属于推断。真实素材/版本问题仍核对，但不以此取代学习主任务。

学习两层：导演怎样安排观看体验；作者怎样把安排写成模型可以执行的正文。保留原案例的表现力度，不自动压成固定、小幅慢推、弱反应。具体电影、胶片、色数、人物、时长和画幅不作为通用默认。

## 从案例反推思考顺序

先记录案例直接写了什么，再提出有依据的设计意图推断：
事件与人物状态 → 观众应经历的感受 → 主体/陪体/前景的分工 → 起始画面与遮挡 → 人物行动 → 摄影机各自由度如何协同 → 沿途新增的信息 → 镜尾落点 → 下一段入口 → 需要哪些资产支持。

对照当前剧本提出具体拍法，不只总结“有电影感”。保持剧情与原文台词，在新人物、空间与事件上重做动作和路线。写法、导演思路及所需资产分别记录；复杂运动本身不是目的，其带来的观看收益必须保留。

## 两个用户认可案例

### 石窟俯拍文戏

直接做法：固定90度俯拍，人物托腮、屈膝、前倾，桌面符纸按色块和物件秩序排列；一只手保留托腮，另一只手拈起红符，伴随纸张与饰物声音。房间、桌面布局、人物、道具、色卡、音色各有独立参考。

可迁移思路：固定画面依靠人物、手和物件改变信息，静止摄影不等于无设计；把道具放在动作可达处，让美术提前服务表演；用人物做事的方式表现从容、好奇等性格。写法按固定构图 → 姿态与物件布局 → 细微生命感 → 对白触发动作 → 单手保持/另一手改变 → 道具新状态展开，不用一句“慵懒地询问”代替。

### 户外庆典组合长镜

直接做法：染布全幅遮挡开场，手掀布揭示舞台；摄影机后撤、建立荷兰倾斜，再围绕舞女螺旋上升，舞女是主要注意中心，群众与被抬行的人物在背景变化中出现；最高阶段前景彩旗翻卷遮满画面，作为下段入口。群体服装用物料系统组合，个体外观保持多样。

可迁移思路：入口、主体表演、群体信息、运镜和出口作为一个完整事件设计；前景既负责沉浸与空间层次，也承担转场；用摄影机运动持续改变背景信息，不一定靠多次切镜。倾斜、旋转、升高可以共同组织热烈、眩晕、释放等体验，但具体意义联系剧情判断，不固定等同醉酒主观镜头。

## 主动设计组合运镜

不能满足于列出push-in、orbit等词汇。为有空间揭示、节奏升级、群体关系、动作跟随或强烈主观体验的关键段落比较拍法时，主动考虑有观看收益的组合运动，并给出推荐；不能所有提案都只是固定与慢推。普通覆盖也可成立，不为凑手法给每镜强加组合。

| 可考虑的组合 | 协同方式与观看收益 |
|---|---|
| 荷兰角 + 环绕 + 上升 | 画面倾斜控制失衡感，围绕主体改变观察方向，上升逐步改变空间与群体关系；连续保留主体注意中心 |
| 后撤 + 升高 + 俯仰调整 | 从个人行动扩展到群体规模或后果，逐步揭示原先不在画内的区域 |
| 侧向跟随 + 摇摄修正 + 前景遮挡揭示 | 保持行动者可读，同时通过视差打开隐藏人物、空间或威胁 |
| 弧线推近 + 移焦 | 改变观看角度与心理距离，把注意从物件/前景交给人物的认知或反应 |
| 低位跟随 + 升高越障 + 俯视落点 | 沿行动路径越过障碍或高度变化，再揭示行动结果；动作路线和摄影机路线分别设计 |
| 连续跟拍 + 脱离主体 + 新主体接力 | 先参与人物行动，再由物件、声源或另一个行动者接管注意，不机械一直跟同一个人 |

荷兰角是画面滚转/倾斜，环绕是摄影机围绕主体的水平路径，上升是高度变化；三者分开设计、可同时执行。镜头俯仰负责看向哪里，不能把“上升”只写成抬头。相同主体大小若必须维持，安排相应跟随距离/取景调整；可变景别时明确变化，不默认全程锁同一裁切。

组合方案写清：
- 起始构图、主体与背景关系。
- 每个分量何时启动、方向、速度变化、叠加或先后关系；必要时用有依据的角度/高度，不硬编数字。
- 人物动作与摄影机运动怎样交织，始终关注谁。
- 各阶段背景、前景新增什么，陪体如何可读；需要时画路线或关键阶段图。
- 各分量何时减速/结束，终点构图与转场载体。
- 下一镜怎样接住同一载体、方向、声场或动作阶段。

用户已指定或选定的组合运动进入提示词时，不得删去倾斜、环绕、升降等分量，只留下“镜头跟随”。发生实际执行失败时定位具体分量与画面结果再局部改，不在生成前凭复杂就取消设计。

## 画布实查后的镜头、衔接与整段制作方法

下列方法来自用户指定的公开画布样本；具体原文、节点、版本和媒体证据留在研究项目。方法迁移到当前剧情，不照抄人物、事件或固定时长。

- 先设计观看链再列镜号。例如威胁全景 → 见证者转头 → 快速变焦接反应 → 听者困惑 → 画外声先入 → 环绕越过遮挡揭示说话者 → 特写继续其表演。每次运动/切镜交接一个信息、行动、声源或反应；不是给每句台词轮流拍正脸。
- 组合运动用相对关系控制。例如追逐镜头的主体略快于摄影机，持续拉开距离；近景地面高速掠过、远景主体缓慢缩小、载体震动、脚步与沙尘共同构成速度感。具体数值由镜头需要决定，不能只写“高速跟拍”。
- 动作接力可以在同镜内完成：跟随对象A → B进入并改变A的状态 → 摄影机交给B并改变取景尺度 → C进入再升级。保持路线与方向，靠注意中心与尺度变化组织过程，不默认每一环都切镜。
- 衔接有不同层级：同镜内由遮挡、视差、声源与动作接管注意；镜间用动作、视线、对象、信息或对白承接；段间可用布料/尘雾等实体载体做出口和入口。根据场次选用，不给每处普通硬切都强塞转场效果。
- 将声场作为整场持续的空间：全景切特写时，远处灾难、群众、风等底层仍在，近处台词/动作浮于其上；对白可以跨画面延续。需要骤停时，明确哪些层停止、哪些底声保留，以及人物如何接住这个变化。不能把每个镜头当成声音重新开始的新地点。
- 群体反应拆成不同对象、行动和延迟：先停手、慢半拍回头、仍在做旧动作、朝另一方向张望等；同一刺激形成错落反应，而非只写“人群震惊”。主角性格也通过其处理刺激的方式延续。
- AI按执行复杂度主动选择两条路线：简单镜段由完整文字承担导演设计；容易丢失动作/空间关系的复杂局部先用故事板落实机位、关键阶段和镜序，视频正文继续规定运动、节奏、声音、身份及最终画风。具体判断见下文自动路线选择，不逐段要求用户二选一，也不强制所有镜头先生成故事板。
- 整集先形成场次节拍、观看体验和镜头关系，再盘点人物造型、服装物料、道具、色卡、场景多视角、局部布局、声音及所需故事板；按依赖制作镜段并保留版本。看到多版本节点，只能确认存在迭代，不推断作者每次返修的原因、选用哪个版本或完整制作时间顺序。
- 复核每段的叙事作用与镜间接力后再剪辑；字幕清理、高清和裁剪作为有需要的后续工序。画布出现这些节点不证明全部段落经过同一后期流程，不把它们全部改成必跑步骤。

## AI按执行复杂度自动选择路线

在场次/镜段设计时，由AI依据当前模型能力、真实参考与可见动作风险选择，简要记录理由，不把路线作为每段都要用户选择的问题。用户明确指定优先；讨论/写稿阶段先交相应设计，生产阶段在现有授权内制作。两条路线均保留完整导演意图和声音设计：

- 路线1，文字承担导演设计：默认用于简单对白、单人表演、清晰的取放物、空间与动作关系明确的镜头。人物/场景/道具/色卡等真实参考仍按需绑定，不等于纯文生或省略资产。
- 路线2，故事板前置：用于视频模型容易丢失的关键可见关系，先把机位、姿态、接触/受力、动作阶段、遮挡与镜序落实到图中，再用正文规定运动过程、节奏、声音、身份与最终画风。正文不能只剩“让故事板动起来”。

| 判断依据 | 适用处理 |
|---|---|
| 单人/普通对话，少量明确动作，持物与空间简单 | 通常路线1，直接编译具体摄影、表演和声音 |
| 多人连续攻防、擒拿/救援、身体交叉遮挡，持手或武器接触容易混淆 | 路线2先验证关键姿态、接触点、受力与结果 |
| 连续追物/抛接、空中翻转、复杂尺度或主体接力，过程阶段容易丢失 | 路线2先验证路径、取景方向及阶段承接 |
| 运镜术语多，但人物/空间清楚，运动可连续描述 | 不因组合运镜本身就强制画板，保持其表现力 |
| 单镜简单但跨镜空间、轴线或复杂动作衔接容易出错 | 对问题局部使用路线2，其余保持路线1 |
| 问题主要是台词太密、声音归属、音色或模型参数 | 在声音/容量/执行层解决，不能把画板当作所有问题的答案 |

判断不按提示词字数或机械人数阈值。多人清晰站立对话仍可路线1；单人复杂翻腾、攀爬、精细机械操作也可路线2。相同情节已有清楚且适用的已审板时复用，不重画；已有图片若只能证明身份，不能冒充动作板。

路线2只覆盖需要它的动作组/切口，不使整集所有镜头统一变成故事板路线。板的格数服从关键阶段；同镜A/B/C与真实CUT分开，按[镜头设计规范](shot-design-standard.md)验画面本身。对复杂关系，文字确认不能代替需要的实际图板验证；画板未完成/未通过时不虚构绑定，先推进独立镜段。画板职责是结构、摄影、动作，不带入分格、箭头或草图画风。

路线1真实生成后若重复出现相同动作/空间错误，保留原结果，针对该问题转路线2；不反复追加文字或降弱动作。路线2实际输入与支持方式依平台当前能力处理，板不能保证视频执行通过，最终仍检查原视频和切口。旧受理任务保持原身份恢复，不为规范升级重新提交。

## 可复用正文写法：组合运动

以下只示范句法，不是所有场次的固定方案：

“前景厚布遮满画面。角色掀开布料时，摄影机随显露的光线后撤，揭示舞台，同时画面逐渐向右倾斜形成荷兰角。舞者开始转身，摄影机承接后撤路径，围绕舞台中心作顺时针弧线移动并逐渐升高；保持已建立的倾斜，让舞者上半身持续成为主要注意中心。随着高度与观察方向改变，台后人群及被抬行的角色从舞者侧后方进入可读背景。接近终点时环绕减速，摄影机继续升至前景旗帜所在高度；旗布从画右向画左翻卷遮满画面，保留连续布料运动与鼓声，下一段从相同运动的布料遮挡接入。”

导演稿说明为什么采用；模型正文写成实际事件，不塞整段理论。按动作节拍把表演、摄影机、声音和新增信息交织，不先堆完全部动作再另列运镜清单。每段依当前模型能力安排容量；资产与同镜阶段图支持复现，不把阶段编号误当切镜。
