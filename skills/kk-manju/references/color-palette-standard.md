# 色卡制作规范：分组板与横向色带板

用户要求做色卡、从风格帧提色、为新场次准备视觉基准或制作三类设定板时读取。先复用已采用色彩设定；无已定方案时从用户指定的风格帧/已选MJ风格图分析主辅色、强调色、光源和用途，提出候选，不宣称推断值是原图原始色值。MJ负责风格探索；把已定颜色清单落实为色卡是资料制作，不重新探索画风。

## 共用输入与验收

记录项目/集数/场次、昼夜/照明、版本、原参考来源、颜色条目（色名、HEX、对象/区域、用途），以及是否用户采用。布局类型与画幅是选择，颜色数量由实际清单决定；13色只是用户两张参考中的数量，不是通用固定数。

色卡是平面制作资料，不套电影截帧的胶片颗粒、景深、镜头畸变、光照渐变或材质纹理。色名、HEX与用途必须一一对应，色块用均匀纯色。参考图的压缩/显示像素不等同于其标注色值；有明确HEX时以标注为目标并核对。模型可能画错文字或色值，出图后查漏色、重复、计数、文字和色块，不把‘提示词写对’当作图已准确。需要精确色值的正式板可按确认后的同一数据进行确定性排版，不能把近似色的AI图宣布为精确色值母版。

## 规范1：按对象分组的制作色卡

用于分别约束主角、敌方/配角、环境、过渡/效果。按项目实际有的组调整，不凭模板虚构角色或血色。每色为有可读边界的矩形色块，上方色名、下方HEX；组标题、色块和文字对齐。图上每组数量、总数和页脚组数必须与数据一致。用户范例为4+3+4+2，共13色、4组；原参考页脚“3 groups”是计数不一致，不继承。

可替换的生图正文：

```text
制作一张横向平面电影美术制作色卡，白色背景，清晰黑色无衬线字体，规整网格和充足留白。标题居中：“{项目/场次} / COLOR PALETTE {版本}”。
使用以下分组与条目：{逐组列出：组名；每色的色名、HEX、对象用途}。
每个条目只出现一次。每组上方标粗体组名，每个色块上方标色名、下方准确打印HEX。色块均匀纯色、细边框、无阴影；统一组内尺寸与文字基线。按条目数量分行，不挤压标签。底部打印按实际清单计算的“{总色数} colors / {组数} groups / Production Reference”。
{本轮画幅与版式安排}。只输出一张色卡资料图。不要人物、风景、材质照片、渐变、立体样板、装饰插画、界面控件或额外颜色。
```

用户图1为约2.35:1宽版：上行主角4色，中行敌方3色，下行环境4色加过渡2色；不机械强制16:9。不支持原比例时按实际模型画幅重新排版并记录，不拉伸色块或裁掉标签。

## 规范2：单行竖色带总览

用于把整段/场次的颜色按约定顺序一次展示。上部大标题和副标题，中部一行等宽等高竖色带，色带下方HEX和简短用途说明。用途文本是颜色与剧情对象的映射，不把色带面积当成成片用色占比。色序按用户已定或项目逻辑；不擅自按亮度重排。小面积强调色可与其他色带等宽，实际面积另记用途。

可替换的生图正文：

```text
制作一张16:9横向电影美术色彩总览板，暖白背景，简洁平面编辑设计。上方居中粗体黑色无衬线标题：“{项目 · 集数/场次 · 照明条件 · PALETTE}”。下一行灰色小字：“{调色方向} · {实际数量} color system”。
中部横排{实际数量}条等宽等高的竖直矩形纯色色带，上下沿对齐，间距相等。按以下顺序从左到右排列：{每行列出：序号、HEX、色名/用途}。
每条下方居中准确打印对应HEX，再下一行用较小灰字写对应简短用途。标题与色带之间、说明与页边之间保留充足留白；标签不能跨列或裁切。底部不添加无关图形。
只输出一张清晰的平面色卡。不要人物、风景、布料/沙地照片、渐变、投影、胶片颗粒、3D透视、界面控件或额外色带。
```

## 流程接入与引用

制作前主动选择适合的规范；用户要复刻某版就用对应版。通常一个已采用的色彩清单即可派生两种排版，不强制每个场次生成两张。保存清单、提示词、参考与输出身份，模型/画幅/质量/数量填执行参数；实际生成仍经KK既定平台与队列。用于剧情截帧时，真实绑定已选色卡，并在正文写清人物、衣装、环境、光源与强调色的职责。黑白项目把用途改编为可读灰阶层级，不把本参考的沙漠色或彩色规则套到所有项目。
