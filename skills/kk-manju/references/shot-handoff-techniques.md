# 镜头之间的衔接技巧库

设计相邻镜头或同镜注意转移时读取；声音细则见[分镜声音设计](sound-directing-standard.md)，跨视频视觉动画执行见[文字站位与转场动画](blocking-transition-standard.md)。AI按剧情主动选用、组合并给出具体方案，不把五种技巧留作名称清单，也不要求每个切口同时使用全部技巧。

## 1. 每次交接明确三件事

前镜交出什么 → 在什么动作/声音/信息变化处交接 → 后镜接住什么并新增什么。单位可以是信息、对象、视线、动作阶段、声源、持续声场或实体遮挡。保留既定台词、地理与人物已知信息；不是任意两张漂亮画面的拼接。

在导演稿中简要写明主要技巧与观看收益。提示词阶段把前镜的终点和后镜的接入成对编译；同镜内则分阶段连写，不伪装成硬切。已有连续接口可直接引用，不重复扩张成冗长表格。

## 2. 信息接力：后镜回应前镜提出的问题

适用：威胁/证据出现、身份揭示、谜题、关系判断与听者反应。

设计：前镜让观众看见一个变化或缺口，后镜给出相关反应、解释或新的疑问。顺序可以先现象后人物，也可以先人物察觉后揭示所看之物，由观众知情范围决定。

写法示例：“前镜让远处异常进入注意，人物刚停下原动作时切出。后镜接人物朝同一声源/对象看去的反应，此刻才让观众读出他已认出异常。”换人不等于完成接力，后镜须确实承接刚出现的信息；不能让不知情角色提前反应。

验收：观众能说清为何此刻切、后镜答复了什么、还有什么未揭示。不要把每句台词轮流正反打当作唯一覆盖。

## 3. 声源接力：先听见，再发现谁/什么在发声

适用：画外插话、入场、隐藏人物、危险/物件声引导发现。

设计：在当前画面引入明确的画外声，安排人物听见及反应，随后用摇、移、环绕、移焦或切镜揭示声源；选择最适合空间与戏剧目的的一种。也可保持声源不入画，有意留下悬念，但必须明确这是设计。

写法示例：“B在画外侧后方先开口；A的目光随声源转动，摄影机弧线移动越过A肩部遮挡，揭示B。B的原句连续，显露时不重说。切到B近景后接其尚未完成的表演。”

验收：先声与揭示的先后清楚、声源方向可对应、说话人和口型正确，镜头没有无故寻找另一个对象。该声音进入与持续写入同一声音事件。

## 4. 动作与尺度接力：跟随的主体和取景逐级改变

适用：追逐、捕食链、递物/抛接、救援、力量升级、从个体扩展到群体。

设计：A正在行动 → B进入并接触/改变A → 注意转交B → 随B的动作改变摄影机路径/取景 → C进入或结果揭示。分别明确交接前后的主体、运动方向、接触与受力、来处去处和尺度参照，不能只写“越来越大”。

写法示例：“摄影机贴地同向跟随A。B从后方进入并改变A的状态时，摄影机顺势接住B的行动并后退扩大取景；下一主体进入时再次接管注意，摄影机延续方向并进一步打开尺度。原对象退出/受力后的状态保留。”

验收：对象没凭空替换、路径与接触可读、相对尺度递进有参照，摄影机变化由事件触发。同镜接力保留连续路径；使用硬切则另写动作匹配阶段。复杂过程按执行复杂度自动采用局部故事板。

## 5. 声场承接：切近了仍身处同一场戏

适用：大场面切人物、对话反打、听者反应、相同空间的多机位。

设计：固定场次持续声层；切镜时承接仍在发生的环境与人物发声，前景重点随新机位调整。声源远近、遮挡和空间感合理变化，不要求所有声源音量永远不变。需要消失时给出退出原因/设计触发。

写法示例：“远处持续轰鸣与散落呼喊跨切口延续；画面切到人物特写时这些声音不重新起头，近处对白清晰浮于其上。下一镜沿用相同场地的声场，保留上一句未结束的发声。”

验收须实际听：无突兀归零或重新启动、无对白重说/截字、无错误混入另一地点的声场；计划中的声音连续不等于媒体已连续。

## 6. 实体遮挡转场：把出口和入口提前布置进场景

适用：场次切换、空间揭示、时空省略或有动机的段间视觉连接。

设计：先在场景中准备可信载体及路径，如布料、旗帜、门柱、人物或尘雾；前镜让它进入前景并形成交界状态，后镜从相容的遮挡、方向、速度/质感接入再揭示新画面。颜色相似是一个条件，不足以代替动作与方向设计。

写法示例：“前镜旗布从画右向画左翻卷，近景布纹遮满画面时切出；后镜从同向运动的布料遮挡接入，旗布继续向左退出，揭示新场景。环境/音乐是否继续按场次声音设计处理。”

前后不能各完整重复一遍遮挡动作；时间跳接须承认省略，不能伪装无缝物理通路。按既定转场卡写载体、交界、方向、切换条件、两侧时长及generated/post/hybrid归属。

验收：前镜确实到达交界状态，后镜真正接住并打开，载体运动与速度相容，人物/道具/声音继承正确。实际未生成遮满画面的素材时不凭正文宣布转场完成。

## 7. 与整集编排的关系

整场先规划信息与情绪流，再为需要的交接选技巧。同一切口可同时做信息接力与声场承接，也可声源先入后用环绕揭示。普通镜内硬切可以靠信息/动作/声音成立；跨视频继续满足项目既定的视觉转场动画要求，不能用声音桥替代已要求的动画。

整集接口至少保留：前镜末/后镜首的可见状态、人物知识与情绪、持续声音及注意对象。路线选择是实现手段，不为套技巧改剧情、重说台词或降低已采用的镜头力度。最终用实际播放与试听检查每个交接，不只查字段相同。
