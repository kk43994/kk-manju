# 单集拆解与视频参考资产

在基础规范、分集范围和画风已确定后使用；首次确认顺序见[用户引导](guided-production.md)。用户给的是单集时只深入该集；全剧材料用于共用角色与连续性，不因此制作未授权的未来集资产。先自动分析和提出方案，再让用户选定实际形象与核心参考；助手完成读取、编号、提示词、工具调用和质量检查。

## 1. 给用户一份本集制作包

使用[单集制作包模板](../assets/episode-production-pack.template.md)，或并入项目现有等价资料。所有统计来自已读原文；未读、缺页或歧义须说明。

| 清单 | 必须理清的内容 | 容易混淆的边界 |
| --- | --- | --- |
| 角色 | 规范名/别名、关系、本集目标与状态、出现的场次、声音类型、所需造型；分别统计实体出场、有声未入画、仅被提及、群众 | 同人多称谓不重复计人；仅提及者不自动生图，群众不凭空逐人补设定 |
| 场景 | 地点、内外景、昼夜、剧情用途、在本集出现次序、入口/出口与主要物件 | 同地换机位不是新场景；同地点昼夜或损坏状态分开记变体，不随意当成不同地点 |
| 事件 | 按原文顺序写谁做了什么、作用对象、结果、反应、观众新增信息、前后依赖 | 不只摘对白；递物、致伤、发现证据、关系变化等关键动作都须保留 |
| 台词 | 稳定句ID、逐字正文、说话人、受话人、对白/心声/旁白/画外声、原文位置及事件关联 | 称呼歧义单列，不靠想象定说话人；不把台词与小说叙述混在一起 |
| 关键画面需求 | 事件对应的可见证据、人物反应、重要道具、必要接触/受力与可冻结瞬间 | 此时是画面需求/草案，尚无媒体就不叫实际截图或已生成关键帧；不冒充完成分镜 |
| 资产缺口 | 对应角色/场景/道具/状态、已有原图与采用依据、需要补制的视图和用途 | 正文出现资产名不表示参考已存在；有图但没选定仍是候选 |

向用户先给可读摘要：“本集实体角色、画外声角色、地点及状态变体各多少；依次发生哪些事件；需要制作/复用哪些资产。”再提供完整清单与台词对应。数量由去重后的实际行计算，不把猜测填成确数。新旧集沿稳定ID关联，在本集明确哪些资料复用、哪些新增。

本集范围已确认且原文无歧义时，内容拆解属于助手工作，不要求用户逐句重新签字。需要改变分集/原句或存在实质歧义时带着具体出处提问。该制作包是后续导演与漏戏检查的来源，生成容器数和镜头数在分镜阶段决定，不能拿事件数直接等同视频条数。

## 2. MJ人物与场景风格候选

用户先定画风方向，再按当前范围用MJ做候选。人物与场景都要能体现同一部剧的媒介、形体、细节、光色与质感；仅一张风景不能证明角色也适合此风格。

- 人物候选明确原文设定、助手设计部分、身份/衣装及当前探索的变化；没有外形原文时给设计理由供选择。场景候选给地点、气氛、年代与关键剧情物件，不提前把未经确认的空间布局当定稿。
- 按项目需要选择代表性角色与场景，列明具体名单和张数再执行；全剧角色清单不等于授权一次生成所有角色。输入齐全的已授权独立人物/场景可并发。
- 可以单图或分格展示；每格标稳定候选号、对象与视图性质。区分“不同设计候选”与“同一设计的多视图”，不能从一个格子选定人物后把其他候选脸也带入参考。
- 给出可看候选、推荐理由与不足，引导选定人物初始形象、场景方向与共同风格母参。记录原节点、单张输出和高清原件；分格图需用选定单幅或清楚隔离的同一身份视图进入后续。
- 用户同时明确选定某张图的画风与人物身份时，两项分别记录即可，不要求重选。选定风格图也不自动证明其背面服装、反向场景或物件结构已经确定。

MJ负责这一步的风格与形象方向候选。后续多视图与状态图沿[图片制作规范](image-production-standard.md)和项目已选工具落实；不把“先用MJ”误解为每张图都要重跑风格探索，也不擅自换掉已选渠道。

## 3. 引导确定视频参考资产

先呈现“为什么需要这类图、建议做哪些视角/状态、已有哪版、需要用户确定什么”。视图与数量根据本集实际拍法需要提出，不默认所有人物六视图、所有场景四张或所有物件一套模板。

| 类型 | 推荐按需准备的内容 | 用户主要确定什么 | 助手核验与视频中的职责 |
| --- | --- | --- | --- |
| 人物身份/多视图 | 清晰身份主图；需要的正面、侧面、背面、三分之四视角；全身/脸部细节；按剧情需补表情或手部 | 选定哪张脸、年龄体型、发型、衣装和多视图方案；哪些外形不可改 | 同一人、同一造型、比例与五官稳定，背面细节相容，所需头脚完整；控制身份/衣装，不把展示姿势和背景带入剧情 |
| 场景/多视图 | 已选场景主图、空间地标/布局记录；剧情需要的主方向、反向、入口/出口与重要活动区域；必要昼夜状态 | 选定空间样貌、关键物件位置及需要补的视角/状态 | 同一地点的门窗、通道、陈设和尺度能对应，光源方向可解释；每张注明摄影机位置和朝向，不把几张漂亮但地理矛盾的图当多视图 |
| 关键道具 | 能辨形的主视图、必要侧/背/结构细节、相对尺度、握持/接触区域；持有人及完整/损坏等状态 | 形制、颜色、材质、标识及关键状态 | 形状、数量、尺度与归属一致；只补剧情需要物件，不为普通背景陈设强制出图 |
| 服装与造型状态 | 基础服装层次/配饰；换装、湿污、受伤、破损等必要变体 | 哪套造型对应哪场戏，状态从哪里开始变化 | 是同一身份的状态变体，保留基版与血缘；不因伤妆换脸或忽然恢复干净 |
| 色卡与成像基准 | 已选风格的主/辅/强调色、角色与环境分配、光影层次；黑白项目记录灰阶层次 | 色彩方向与关键对象本色是否合适 | 作为配色和成像依据；不把色卡版式、文字或人物板分格复制到成片 |
| 声音参考（适用时） | 角色语言/音色/表演试听与可复用来源 | 哪版声音合适、语气和速度是否符合人物 | 当前模型确实支持时才绑定，保留原文与说话人；无稳定控制能力如实说明，不以提示词保证音色一致 |

制作时先复用已采用母版。新角色/地点的核心形象尚未定，先让用户选择；已有身份与方案已定的普通派生可按用户明确标准检查，不机械把每张重复交回。多个已定角色的多视图共享母参时可并发；需要新的前置主图时保留真实依赖。

先做技术/语义检查，再给用户看核心资产候选并提出推荐。必要视角、脸、衣服、几何、道具或接触错了，指出具体问题，不能只说“清晰度合格”。用户选择确定版本后记录采用；助手受托选择的单列依据。仅同意“做多视图”是制作方案，不冒充对尚未生成多视图的视觉验收。

## 4. 从资产包进入分镜和视频

本集资产表逐项记录：对象与状态、原文/事件用途、图像原件或真实节点及单张输出、版本/指纹、用户采用或明确受托依据、控制职责、仍缺的视角与待返修问题。人设母版、场景母版与风格母参可来自同一图，但职责分别说明。

核心身份、场景与参考方案确定后完成本集正式分镜，按具体机位补真正需要的派生视角，避免资产阶段凭空制作大量用不上的图。只有相关镜段必要参考确实可用、已按约定审查且范围已授权，才编译为可提交视频任务。分镜揭示新缺口时回到对应资产局部补齐，不重置全剧画风或重新选所有人。

提交前建立“镜号 → 人物/场景/道具/状态 → 实际参考 → 角色职责”的绑定表，按当前模型的数量、格式与输入职责限制安排。同一多视图板上的角色不能在视频里变成多人；只有用户/导演指定的严格首帧才按首帧使用，不把人物板或场景总览硬塞成剧情首帧。正文与真实参考输入一起回读核对，文件已在本地不等于平台已经绑定。

成片画幅沿已确认值。人物多视图板、道具板和色卡属于制作资料，版式可为可读性另设；不能因此改变视频横竖屏。剧情冻结帧与严格首帧按目标镜头画幅和当前工具能力准备。

进入下一集时恢复这份制作包和共享资产；先盘点新角色、新地点、新造型与状态变化，再补缺。前集结束的衣装、道具归属、人物知情和声音延续都与新集起点对照，已确定且适用的规范不重复问。
