# 视频提示词通用规范 V1

日期：2026-11-04
状态：用户确认纳入 KK独家漫剧的通用规范。适用于把既定分镜转换为视频生成指令。

本规范负责表达与执行转换。镜头的职责、景别、机位、调度、运镜和切点由[01-镜头设计规范-V1](shot-design-standard.md)确定。题材、画幅、片长、画风、语言、模型版本、参考模式及分辨率均来自项目配置。

## 一、这套规范负责什么

输入：

- 当前剧本与允许的改动；
- 镜头设计卡及镜序；

- 人物、空间、道具、光色和声音设定；
- 本次可用的真实素材与各自职责；

- 目标平台当前可用的参数与参考方式。

输出：

- 对应镜号清楚的完整提示词；
- 素材绑定清单与正文中的用途说明；

- 提交参数和每个片段的出入状态；
- 未落实的输入与影响范围。

转换时保留导演方案。不能为方便生成，悄悄取消反打、把多镜改为单镜、删掉人物反应、换掉运镜触发或放慢台词。发现执行难点时，定位到具体镜头，回到镜头设计层作有依据的调整，再同步提示词。

模板、讨论草稿和实际提交稿要明确区分。占位符可以存在于模板中；实际提交稿须把用到的素材、人物、台词和参数填实。

## 二、编写顺序

1. 核对当前分镜版本和实际采用素材，避免从最新文件名推断用户已经选用。
2. 根据镜序、动作与对白容量规划生成片段。片段长度服从当前模型能力与剪辑需求；不以固定秒数重排剧情。继承导演阶段按执行复杂度作出的[文字/故事板路线选择](case-based-camera-design.md)：简单镜段直接展开，复杂局部将已审板实际绑定并说明镜号/阶段职责；不把未制作的板写成已有参考。

   用故事板约束视频时，依[故事板到视频的摄影执行与节奏](storyboard-execution-and-pacing.md)逐格编译。每格先定真实切镜还是同镜运动，再写机位、景别、触发、摄影路径、焦点、落点、声音和前后格交接；最终提示词和已绑定的图片页/格须能一一追溯。模型返回后按同一格序审查，不以“提示词写了运镜”代替实际拍到。

3. 登记每个片段的开场状态、镜头清单、镜尾状态及依赖。
4. 选择必要参考并定义职责；正文引用和真实输入一一对应。

5. 按统一正文版式编写。
6. 对照镜头设计检查遗漏、矛盾、重复与被无意简化的部分。

7. 正式执行前用当时的平台信息确认参数和素材可用；生成后再核对实际输出。

并行任务可以共享已经确定的角色、空间和切口设计。某片段若依赖前段真实产物，须等待该产物；计划中的尾帧、声音或速度不能当成已经拿到的输入。

## 三、通用正文版式

采用连贯、可直接阅读的段落。中文为主并配准确英文摄影术语，是本套规范推荐的写法；具体语言仍可按项目和模型调整。英文术语与中文描述须一致。

### 1. [STYLE LOCK] 影像风格

填写本项目已确定的：

- 影像类型与美术语言；
- 画面材质、皮肤/表面表现、颗粒或线条特点；

- 明暗层次、高光、暗部、色彩关系与光源逻辑；
- 镜头透视、景深和运动质感中需全段保持的部分。

风格锁可适用于实拍、动画或其他风格，不默认使用某种胶片、摄影机、画幅或摄影师。用参考名称时同时说明希望保留的可见特征。真实拍摄设备名称在生成任务中属于视觉意图，不能据此声称结果由该设备拍摄。

风格锁说明共同影像基础；某一镜如何构图、移动和切换仍在逐镜正文中写清。场景光源发生变化时，说明变化原因和连续关系。

### 2. 本段范围与规格

写清：

- 本段时空、预计时长、画幅；
- 对应镜号、单镜或多镜；

- 从哪个事件或状态开始，到哪个结果结束；
- 必要的一句叙事或观众体验目标。

“连续无切镜”只用于真正的单个长镜。多镜片段明确切镜位置。生成时长、成片选用时长及需要的剪辑余量分开记，不能把余量变成长时间空等。

把模型最大时长视为容量：同一空间与连续因果可在一个 15 秒容器里承载多次信息、动作和对白变化；短事件选更短的合法时长。先估正常语速与动作能否并行，再决定容器边界；遇到必要接触、真实续接或发声归属不清时拆开，不为增加密度压坏表演和字音。

按用户制作偏好，每次视频生成都在首尾安排可剪辑余量。通常先按两端各约0.5–1秒规划，再根据具体动作、表演和切点调整；数值是制作起点，不是模型保证。余量包含在本次模型的总时长上限内，例如15秒生成扣除两端后通常留约13–14秒正文。分别记录头余量、正文区间、尾余量、预计采用区间及对白保护范围；余量保持自然动作、视线、衣料或环境延续，不新增台词，不冻结、不黑屏、不让演员空等。关键因果及必要字音不能落在默认可裁区间，实际可用余量须生成后播放核对。

行礼、递物、攻击、防御等有明确对象的动作，视频正文要同时给出发起者、对象、双方可见位置、目光方向、动作路线和接触/结束状态。若对象在关键瞬间不入画，先设计能被模型看见的空间关系或单独构图参考，不用重复否定句代替。第三集 Fast 试片中，文字写了「向叶宇行礼」，实际女孩向林静雯躬身；因此这类对象关系镜先用清楚的双人或三人构图固定对象，必要时与复杂运镜拆开生成，审查实际朝向后才能采用。

预计同框四人及以上时，或两三人关系复杂时，按[多人复杂站位的执行锚](blocking-transition-standard.md#多人复杂站位的执行锚)先定空间、再编译正文。最终提示词用一小段“站位锚定”写明固定地标、摄影机工作侧、每个可见人物的身份与画面位置、身体/视线方向、入画和画外边界、各阶段准确可见人数、前后镜左右顺序及动作对象。可引用本地 TXT 作导演证据，但视频模型只接收最终正文或平台实际支持并已绑定的附件；若改用 Image2 站位图，写明真实图片节点和只控空间的职责。不得声称未挂入任务的图已生效，也不得靠堆“不要重复人物”替代位置和取景设计。

### 3. 音轨与表演基调

说明环境底声、事件音效、声音空间、表演节奏及配乐处理。

人物的音色、情绪和语速分别说明。例如参考音频只负责音色时，不让试听台词或慢语速自动进入新片段。没有指定声音参考时不虚构已绑定音频。

声音从分镜阶段依[声音设计规范](sound-directing-standard.md)设计：进入触发、持续范围、退出方式、声源性质/远近、人物回应与摄影触发都须落实。在逐镜正文中随对应事件写出变化，跨镜持续的声音由同一事件承接；骤停逐项指明停什么和保留什么，不用“全部停止”误删设计中仍在的底声。

此处给出声音的整体原则；逐字对白集中在后面的声音时间线，仅写一次。声音事件表、逐镜触发与时间线引用同一事件，不三处重复台词。

### 4. 参考素材及职责

每项包含：
**实际素材标识 → 对象 → 控制维度 → 适用镜头/阶段 → 不继承的无关信息。**

按任务需要选用，不强制每条都挂齐以下所有种类：

| 参考类型 | 主要职责 | 需特别说明的边界 |
|---|---|---|
| 人物身份、多视图 | 脸、体型、服装和可辨认特征 | 不复制图板分格、白底、展示姿态；多个角色分别对应 |
| 场景、多视图 | 结构、地标、材质与空间关系 | 每个机位看的是同一空间的不同方向，不把参考构图锁到所有镜头 |
| 道具 | 外形、尺度、材质与必要细节 | 持有者、持物手及使用过程由分镜决定 |
| 色卡、色彩方案 | 色彩层级、主辅色和肤色关系 | 不生成色块、文字或卡片；剧情新光源的变化仍应成立 |
| 画风或质感参考 | 光色、表面质感、颗粒、线条等 | 只作风格时，不继承人物身份、动作、背景布局或剧情状态 |
| 状态参考 | 某阶段的外观与物件结果 | 说明开始生效的事件，避免结果提前出现 |
| 构图、站位、故事板 | 对应镜头的站位、构图或关键动作 | 说明适用镜号和范围；是否严格固定起点由任务模式决定 |
| 实际视频、首尾帧 | 已有动作、节奏、构图或续接状态 | 分清查阅、风格参考、状态参考和严格起始帧；作用不能混用 |
| 声音 | 某角色音色或指定声音特征 | 台词、语速、情绪及声源位置按当前设计明确 |

参考素材在提交时作为输入；“中途生效”描述适用的剧情阶段，并不表示模型播到某秒才上传图片。全能参考、首帧、首尾帧、延长等模式的实际能力由平台适配处理。

通用规范不写死节点语法、编号规则、数量、像素或比例上限。实际提交时按当前平台格式绑定，不能把内部槽位编号猜成平台引用。

### 5. 开场画面与承接状态

独立任务写全它需要知道的状态：

- 空间地标、人物位置、面向、视线与身体支撑；
- 摄影机所在工作侧、起始构图与焦点；

- 关键道具的持有者、手、位置及状态；
- 当前衣装、外观、损伤或其他剧情状态；

- 已经发生的事件、角色已经知道的信息；
- 开场仍在持续的声音。

“接上一段”不能替代这些信息。前段尚未生成时标为计划状态；前段已经选用时核对实际画面，分别记录接受了什么偏差、哪些必须修复。

### 6. 逐镜正文

每镜以镜号、时间范围和景别开头，可按动作节拍分段。完整表达：

**前镜转场接入与起始构图 → 人物起始状态 → 动作节拍一及其摄影机执行 → 动作节拍二及其摄影机执行 → 结束状态 → 转场带出与下镜接入。**

人物动作与摄影机运镜写在一起。每个动作、反应或可见事件后，立即跟随对应的摄影机执行：在什么动作发生时开始，朝哪里、以什么速度移动，持续关注什么，在什么构图停住。一个镜头有多个节拍时逐次配对，不先写完全部表演再集中补运镜；连续运动可以写“继续沿原路径跟随”，不因换段而重新启动。固定机位也写清此刻保留的构图、焦点与动作可读范围，不能为了填写运镜强加移动。纯环境或道具镜头以云层、光线、物件变化等事件代替人物动作。

转场带出紧接最后一个动作与摄影机终点。下一镜开头复述同一转场的载体、方向、交界状态及揭示方式；区分模型生成与后期执行，不能只写“自然衔接”。

摄影机执行须覆盖：

- 固定还是移动；
- 为什么在这一事件发生时开始运动；

- 方向、路径、速度、必要幅度；
- 始终关注什么、何时移焦；

- 在什么构图或表演上结束。

这里的“为什么”转化为可观察触发。例如写“她停手抬眼时开始推近”，即可落实导演理由；不需要在模型正文中展开整段摄影理论。

表演写可见行为和先后关系。复杂动作按需要写接触、支撑、受力、落点与释放；轻微动作不堆满无关身体参数。同镜内的动作节拍无需伪装成多个镜头。真正换机位或剪接则另列镜头。

使用准确术语，如 close-up、over-the-shoulder、push-in、pan、tracking、locked-off、rack focus，并给出对应执行描述。形容词应有画面依据。

组合运镜按[案例导演思路与组合运镜](case-based-camera-design.md)编译：将画面倾斜、摄影机环绕、升降、跟随、移焦等实际采用分量逐阶段写入正文，明确何时叠加、保持或结束。人物动作、摄影机变化与沿途新增信息交织展开；不把导演的“荷兰角螺旋上升环绕”等设计缩写成泛泛“镜头跟随”，不以固定或慢推悄悄替换。固定镜头同样借人物、道具和声音变化实现观看设计。

### 7. 完整声音时间线

按顺序写：
**发声窗口 / 声音事件标识 / 声源或说话人 / 画内、画外或内心性质 / 逐字台词或音效 / 与画面关系。**

- 每句逐字台词在同一提交正文中只出现一次，视觉段引用声音事件或关键触发即可。
- 对白沿用当前认可剧本；不得自行补人名、日期、解释、语气词或重复句。

- 连续跨镜的台词是一段连续表演；切画面后不从句首重说。
- 台词预算包含正常发声、停顿和呼吸；需要看清的动作另核容量，能自然并行的内容可以重叠。

- 没有对白的镜头照常说明环境声或静默；嘴部动作由表演决定。
- 口型要求与声源性质对应，内心独白通常不作为画内说话口型。

- 音乐是否生成、后期统一还是沿用已有音轨，依据项目声音方案。
- 时间范围是执行目标；精确切点与声画同步需要实际产物验证。

字幕、画内标牌与屏幕文字分别说明。画内文字如承担关键剧情证据，写清文本、承载面和可读要求，并按执行能力安排生成或后期；不编造源文本未确定的事实。

项目采用后期统一字幕或无字成片时，提交正文明确不生成对白字幕、人物姓名牌和身份介绍牌；剧情必要文字单独声明。沿用已选声音参考及当前台词，不让换画面或增加转场自动触发重配音。

### 8. 收尾与下一段接口

按[衔接技巧库](shot-handoff-techniques.md)把已选信息、声源、动作/尺度、声场或实体遮挡接力写入前尾后头：前镜交出的对象/信息/声音/状态、交接触发、后镜承接与新增内容。声源先入后揭示、跨镜对白及持续声场不能因换画面重新起头；声音事件与人物知情/反应状态一起继承。

需要转场动画时，按[文字站位与转场动画规范](blocking-transition-standard.md)将同一转场卡分配到前段尾和后段首。正文保留具体的动画载体、运动方向、交界画面、切换条件与各侧时间；模型执行部分写进生成正文，后期部分留在编辑执行单。站位俯视图用于作者校验，其文字占位符不渲染到成片，实际空间关系仍写全。

写清镜尾人物位置、姿态、目光、道具与持物手、动作进度、外观、摄影机终点和仍持续的声音。

标明下镜或下段接什么。动作匹配或正反打允许换机位；严格同镜续接才需要相应的实际输入与续接方式。不要把所有切镜都强行改成前段尾帧的重复。

分镜要求剪辑余量时，说明开头/结尾仍在持续的动作与声音，分别记录生成区间和预计采用区间，不要求演员长时间空等。后期才实现的叠化、字幕、曝光/失焦处理记入剪辑单；模型只生成所需干净素材，避免效果叠加两遍。是否产生了足够余量以真实解码画面为准。

### 9. 本段必要约束

只放与本段直接有关、且有来源的边界，例如人物数量、状态生效顺序、关键道具归属、特定字幕处理。优先描述正确可见状态，必要时保留明确排除条件。

避免堆叠互斥指令，例如一边要求全程固定，一边要求连续环绕；一边要求多次硬切，一边要求无切镜。

## 四、可复用空白模板

以下是编写模板，不是可直接提交的实际提示词：

```text
[STYLE LOCK]
〈当前项目的影像语言、材质、光色、透视与持续性要求〉

本段：〈时空、时长、画幅、对应镜号、开始事件与结束落点〉
叙事目标：〈一句话概括本段对观众的作用〉

音轨与表演基调：
〈环境、声音空间、音色分工、节奏与配乐安排〉

参考素材：
〈真实引用〉作为〈对象/维度〉参考，适用于〈镜号/阶段〉；
保留〈特征〉，不继承〈无关信息〉。
〈根据实际任务逐项填写〉

开场：
〈空间地标、人物关系、身体与道具状态、摄影机位置〉

镜头〈编号〉 [〈开始—结束〉] · 〈起始景别—结束景别〉
〈前镜转场接入、起始构图及人物状态〉
〈节拍一时间〉〈人物动作/反应〉；摄影机〈由此动作触发的固定或移动、方向/速度、关注对象与落点〉。
〈节拍二时间〉〈人物下一动作/反应〉；摄影机〈承接上个机位和运动状态的执行〉。
```

## 六、提示词自审与返修

### 6.1 转换完整性

逐镜对照导演设计：

- 镜号、镜序、景别和机位是否保留；
- 运动触发、路径、注意对象与结束构图是否保留；
- 每个动作节拍后是否紧跟对应摄影机执行，连续运动是否承接，固定机位是否也明确；

- 关键动作、反应、对白及切点是否保留；
- 前后状态与声音是否能接上；

- 必要参考是否真实存在、实际绑定且用途一致；
- 时长和参数是否符合本次平台能力。

对白原文、编号、时间加总、引用是否存在适合程序检查。情绪是否成立、镜头是否有力量、表演是否自然需要创作判断和观看。

### 6.2 局部返修

分别诊断：

1. **设计问题：** 信息顺序、观看立场、景别、节奏或切点本身不成立，回到镜头设计规范修改。
2. **表达问题：** 设计清楚但提示词遗漏、歧义或自相矛盾，修正转写。

3. **输入或执行问题：** 素材职责冲突、参数不匹配或生成结果没有实现指令，按证据修正输入或执行方案。

返修记录保留已有效的镜头设计和参考，点明本轮改变了什么。若调整了多个变量，复盘时不把结果只归功于其中一句术语。

生成完成、提示词核对、画面自审和创作者采用分别记录。截帧可以支持外观、构图与某一状态的检查；动作节奏、声音及连续性需要实际播放判断。
