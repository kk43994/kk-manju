# 剪辑、声音与成片验收

用于已有素材的组接、精修和交付。先读当前剪辑单、用户最新反馈和真实媒体；保持[镜头设计](shot-design-standard.md)与[视频提示词](video-prompt-standard.md)两套规范独立。本规范记录后期选择及向上游反馈的接口，不要求每次重做整集。

## 1. 锁定本轮输入和改动范围

每版记录采用的视频来源、真实入出点、选定声音、画幅/帧率、文字政策、音乐与当前修改目标。文件名“最新”不代表采用；用户说效果改善，记录正向反馈，不自行升级成整片锁定母版。

- 修剪辑时保留已有效的镜头与表演；修声音时尽量保留已选画面；删除文字时从干净画面和文字层重新合成。
- 对白字幕、人物姓名/身份牌、剧情必要文字分别配置。无字导出与含字导出可共享同一画面/声音母版，不反复在压缩成片上叠层。
- 新版另存，保留旧版、剪辑单与来源。项目人物、B版音色、480p、具体转场帧数等只留在项目记录，不写成所有项目的参数。

## 2. 先建立可用区间和节奏

在实际视频里找动作起势、接触/受力、结果、发声与反应的可用带；排除重复动作、空等、表演漂移和坏帧。对白按当前剧本核字，ASR仅帮助定位，不用识别错字改台词。原句允许跨画面，但不得重说、截断字音或凭空补句。

反应、动作和说话可以同时发生。能在听者画面上落下的后半句，可采用L-cut；下个声源先到、画面后到可采用J-cut。为了让句意落地而留下的静默仍可保留。片段长度由实际推进和反应决定，不为凑15秒/30秒延长内容。

用户取消总片长限制后，撤销当前计划的对应硬限并保留修订记录；不再为旧时长压缩停顿或补空镜。先分清有意义的反应停顿和生成片尾多余停留。

每个CUT保存来源版本/指纹、源入点/出点、成片入点/出点和取舍理由。使用叠化或动作重叠时，另记两侧真实可用余量（handles）与覆盖窗口：不能取到素材最后可解码帧之外，也不能把冻结尾帧伪装成运动余量。总时长是否变化写明；缩短后更新受影响的声音与文字时间，不靠尾部补帧补时。

## 3. 按切口问题选择连接方法

已有设计转场动画时，先回读[动画执行卡](blocking-transition-standard.md)中的归属、可见时长、交界锚点与两侧阶段。模型已生成的效果不再后贴第二遍；post/hybrid方案只执行明确分配给后期的部分。动画时间与handles分开，按真实素材择切并检查是否改变总长，不从设计卡存在推断效果已经渲染。

先看切点前后正常速度的片段，再逐帧确认问题。记录“观众应感到什么—实际哪里跳了—选何种承接—修后检查什么”。没有问题的切口可直接硬切。

| 实际问题与表达目的 | 可用处理 | 成立条件与限制 |
|---|---|---|
| 动作仍在发生，切换后动势突然断开 | 调整动作切点、匹配方向；必要时短促数字推近、轻微回弹或方向模糊 | 起势、接触、受力方向和结果要相容。效果随动作衰减，不能制造原来不存在的击打。数字裁切推近不会产生真实移机视差 |
| 画面换人后对白和情绪断裂 | 保持一句表演完整，L-cut落在听者反应上；连续空间底声 | 保留说话人归属和口型关系，避开两路对白叠说；不要把反应排成每句后的空等 |
| 物件或感觉触发闪回/回忆 | 视觉对应、短叠化、局部光色/焦点变化，配合环境声J/L-cut | 有清楚的记忆触发与返回落点；检查双脸重影、长时间两空间叠加，避免所有换场统一闪白 |
| 非关键过程允许省略，直接组接却像姿态瞬移 | 先试结果镜/反应镜；需要时用短暗场或明确时间跳接，声音继续 | 前因和后果可推知，省略不掩盖关键救援、道具转移或致伤过程。暗场表示省略，不能声称已补出缺失动作 |
| 濒死、苏醒、梦境等主观意识发生变化 | 短暂失焦、亮度变化、声音空间收窄后恢复 | 由主观事件触发，落回新空间中的清晰主体；不遮住重要表情，不把全画面长期变软 |
| 身份、场景地理、持物手或关键因果互相矛盾 | 换可用素材、调整覆盖，或回上游补对应镜头 | 转场效果不能让矛盾成立；先定位责任层，不用全片慢动作、固定机位或统一叠化掩盖 |

这些是选择依据，不是固定套餐。效果幅度、长度与素材帧率、动作速度、画面分辨率一起判断；低分辨率素材放大会损失质感。先做局部切口样段，再把有效处理放回全片，正常速度检验节奏与情绪。

剪辑单对每处效果记录：CUT/时间、叙事动机、使用的真实余量、画面窗口、声音窗口、是否改变总时长、是否有意黑场/静默，以及实际回看结论。

## 4. 声音先保留表演，再处理接缝

用户选定的音色和表演作为本轮基线。上传音频、克隆参考和可调用的服务端voice ID是不同对象；不能把带环境声的试听片段当成纯净音轨或固定音色ID。声音参考只负责什么、台词和语速由谁控制，要分别写清。

画面修订优先沿用已选对白，不因加转场重新生成全段人声。对白、环境/动作声、音乐在有独立素材时分轨；只有混合音轨时明确限制，避免假装能无损分离。J/L-cut保留完整发声与必要呼吸，声音桥的进出点不必与画面切点相同。

保存独立的画面与声音入出点，并对已核对的发声区间设保护范围。边缘淡化须落在句首前/句尾后；十几毫秒去爆音不等于空间声音已经连续。需要底声桥时只取真实无对白区间，检查是否带入别人的台词、动作或不相容环境。混合音轨无法恢复的字尾不要用虚构底声或静音冒充修复。

混音处理只加一次必要的限幅/响度链。先验证原始对白在剪辑时间线里的位置，再查插件延迟、重采样和编码延迟，避免重复limiter让声音偷偷后移。测量最终编码MP4的响度/真峰，目标由项目决定，不固定本例的数值。

声画修订的检查按任务选择：

- 试听切点、句首/句尾、长停顿和环境声衰减，检查被吞字、双人串声、泵动、音色突变与同步。
- 声称“保留对白时间/表演”时，对代表性语句比较采用基线与最终混音的位置；可用波形对齐检查相对延迟。波形相似不等于音色质量通过，合理混音/编码也会改变相关系数。
- 仅替换音频且声称画面不变时，核对画面帧或视频包指纹；仅删除文字时不要同时偷偷换音色。

## 5. 文字作为独立层

视频生成前按项目注明是否需要干净画面。后期字幕与姓名牌在代码/时间线中各自可关闭，剧情必要的手机信息、信件、日期等另列，不能因为关字幕一并误删。

用户要求去字时，先识别来源：

1. **代码叠加层**：关闭对应文字层，从无字母版重导。不要对已有无字素材再做修补。
2. **模型已烧入画面**：优先干净版本或不损失关键构图的可用区间；裁切须确认表演、接触点与画幅仍成立。局部修复须看时序，检查残字、边缘和漂浮补丁，失败候选不进入成片。
3. **字幕需保留**：以原台词为文本母版；显示时可按用户要求去标点、调整字号与位置。保存显示转换，核对转换后的文本不丢字、不改姓名。字号随画幅、观看设备和主体避让判断，不固定为某个像素值。

无字交付检查原字幕出现区间、姓名牌区间和转场附近，并补全片抽样。OCR用于定位，最终看实际帧；“抽查无命中”不等于逐帧证明无任何文字。文字文件仍在归档目录，也不等于已被渲染。

## 6. 卡顿与导出的技术检查

容器显示24fps、包数正确、时长对齐，都不能证明每帧正常解码。使用[导出核验脚本](automation.md#成片完整解码与交付比对)检查实际文件，重点包括：

- 完整解码视频和音轨；对照剪辑单核对实际解码帧数、时间戳单调性及预期CFR步长。不要靠强制CFR自动复制帧掩盖源片缺口。
- 对无损中间片段直接concat时统一编码器版本/参数、像素格式、尺寸与时基；相同`.mkv`扩展名不保证可直接拼包。实测曾因FFV1 level 1/3混用导致片段丢帧。优先分别解码再拼接，或统一重编码，并验证拼接结果。
- 按每个切口、补丁、裁切和转场窗口看前后帧，正常速度播放。黑帧、静帧、闪光和静音先与设计记录比对；有意暗场不自动判坏帧，PTS连续也不能排除重复画面或源生成运动僵硬。
- 改帧率、裁时或重混后重查声画同步。光流补帧只在确有需要且检查通过时用；它不能修复错误表演或空间关系。

脚本通过后仍需正常速度看剪辑，听声音。报告分开写技术实测、视觉/听觉自审、未测项和用户反馈。

## 7. 交付锁定到实际文件

最终导出记录绝对路径、字节数、SHA-256、画幅、实际时长/帧数、音轨、文字政策与采用来源。上传后回读服务端节点/资源；按约定展示聊天并同步画布，已有原生成功卡片无需重发。

使用LibTV时，按当时工具契约完成上传与官方交付。若返回`review_pending`，保留原fileRef、完整参数及幂等键，等待后按同操作恢复，不重复上传字节或换键。明确拒绝或超过本轮有界重试后报告真实状态，不无限重试。

先发现并核对当前平台的时间线、转场、音频与字幕导出能力，能满足要求时优先使用原生编辑。保存时间线不等于导出实现同一效果；挑代表切口做实际导出并抽帧/听声音。接口缺少某能力时记录当前限制，再以本地脚本补足；不把某次连接的能力开关写成平台永久限制。原生试片、可编辑时间线和最终合片分开命名、分组，避免用户误选。

交付清单不是本地保存证明。需要下载交付时实际保存官方文件；同一原文件交付可比较字节/指纹并解码，平台转码则记录派生关系并检查转码版本。原生预览能交付时直接使用，不为绕开显示限制另行下载。用户观看、效果反馈与最终采用分别记录。

## 8. 把剪辑经验回传到设计

反复需要靠后期补救的切口，回到镜头设计记录真实问题：终态、动作进度、视线、景别差、可用覆盖与声音承接。下一轮提示词只写该段需要生成的状态/余量和声音边界；计划后期实现的字牌、叠化或曝光效果保留在剪辑单，避免生成和代码重复施加。
