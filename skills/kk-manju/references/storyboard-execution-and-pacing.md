# 故事板到视频的摄影执行与节奏

适用于已决定用故事板约束视频的镜段，以及自审发现镜头重复、静止过久、台词容量浪费时的返修。普通文字导演镜头仍按镜头设计规范执行；审片故事板若只供人看，不自动挂入视频。

## 1. 先定观看节拍，再定容器秒数

将剧本拆成会改变观众所见或所知的节拍：进入、揭示、动作触发、接触、反应、决定、声音转移。每个节拍写其戏剧作用、最短可读动作/台词与可同时发生的表演。能同时发生的声音、走位和反应排在同一时间窗；必须等待接触结果的动作顺序执行。用试读、原片声音和实际回片校正估时。

模型的 15 秒是可用容量，不是默认镜头长度或每条只容纳一个剧本事件。相邻节拍共享空间、人物状态和摄影轴，且能在一次生成中保持清楚的因果时，可把多个镜头或对白/反应装进同一个容器；需要真实前段尾帧、复杂接触、换地点或会造成台词归属歧义时拆开。反过来，无对白的入场、转身、递物等短事件不因模型支持 15 秒就拉满。不能为了“更密”牺牲字音、表演转折、关键接触、用户认可的强镜头或必要静默。

定时先列`有效剧情窗口`，再为本次生成加入真实可裁的首尾运动余量，最后核对当前模型最短/最长时长。余量是持续的动作/视线/环境声，不是演员空等、慢动作填充、冻结或黑屏。正文按需要设置，不机械套两端固定秒数。每条记录：生成总时长、预计选用区间、各节拍时间窗、对白保护区间、首尾余量及与前后镜的交接。声画允许并行，但同一句不能在两个容器里重说。

## 2. 把故事板逐格编译成可执行镜头

每格先明确它是`真正切镜`、`同镜运动阶段`还是`仅供理解的状态图`，不能因为纸上有四格就强迫视频在四处切。给执行格保留稳定的`页号/格号/镜号`；逐格记录：

| 字段 | 必须说清的执行内容 |
| --- | --- |
| 观看任务 | 此刻观众先注意什么、上一格留下的问题由谁回答 |
| 景别和机位 | 画面大小、摄影机工作侧、高度/角度、画面左右与可见人数 |
| 人物/道具 | 起始状态、动作触发、实际接触/受力、结束状态与唯一归属 |
| 摄影机 | 从何处开始、由什么触发、向何方向以何速度运动、途中揭示什么、落在何处；固定机位也写保留的构图和画内变化 |
| 切换 | 切前动作/声音，切在何时，下一格怎样接住；同镜阶段写持续的路径而非伪造 CUT |
| 声音 | 进入、持续、距离/声源、退出或跨镜传递，以及人物/镜头如何回应 |
| 时间 | 该格预计时间窗、对白/动作保护范围、可裁余量 |

提示词按这些格的真实播放顺序展开。每个动作/反应紧跟摄影机执行，不先堆完动作再另列泛泛的“运镜”段；荷兰角、环绕、上升等组合分别写起止和同步关系。若板画的是足部极近景→肩后揭示→扶人近景→五人关系镜，正文也按这个顺序交代每次切换、机位和焦点，不能退化成一个持续大全景。视觉板的景别跳变要映射到视频观看问题，不能只靠提示词里的术语宣称已拍到。

复杂板通过人数、轴线、接触和道具核验后，才可作为执行参考。确实要交给模型时，上传该版图片为真实节点，连入视频任务，在正文以实际节点 ID 指明每页/格只控制镜序、构图、动作和摄影；人物多视图、场景与色卡各守身份、地理和最终色彩。站位图单独锁人数与位置。回读最终节点的图片列表和展开正文，核对格号、参考顺序与职责；仅在本地有文件或正文写“参考故事板”不算绑定。黑白分格、线条、标注和站位符号不得进入彩色成片。

项目镜段可复制[故事板执行映射模板](../assets/storyboard-execution-map.template.md)，把格号、镜序、时间、真实节点和回片差异落到同一张表。模板是记录载体，不能替代导演判断或平台回执。

## 3. 自审与剪辑中的节奏复核

先按正常速度完整播放，再逐节拍记录计划与实际：事件是否发生、哪一刻开始/结束、摄影机是否真的到达板上的落点、台词是否在正确人声上、哪些停顿在改变信息或情绪。抽帧只能辅助核人数/构图，不能代替运动与声音审查。

对拖沓先定位具体来源：重复揭示、同景别长时间无变化、动作结束后仍等待、对白完了镜头未交出、首尾余量被当正文、多个相邻镜头重复同一信息。优先用真实可用入出点、J/L-cut、反应与对白并行或删掉重复覆盖来收紧；记录缩短前后时长及保留的叙事信息。若可剪区间不足、因果被跳过或板上关键摄影没被执行，回到该镜重写/返修，不靠后期制造虚假的动作。

“更密”不等于每秒都切：有新的表演、期待或声音变化的停留可以保留。完成整集剪辑后再看一次情节推进，检查一段 15 秒实际承载了多少有效变化，而非以镜头数或时长单独评价好坏。
