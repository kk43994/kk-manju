# 转绘剧与海外本土化规范

将中国影片制作成面向目标国家或地区的本土化版本。按本轮范围替换人物、场景、语言台词与中式道具，保留原片剧情、人物关系、镜头、表演、动作与节奏。用户另行要求改编或重新导演时，单列变更范围和版本。

## 1. 项目选择与原片入口

- 记录目标国家/地区、需要时的具体地域与时代背景、对白语言/口音、字幕和画面文字语言、画风、平台、模型、交付规格与本轮范围。国家、语言和人物族裔分别选择；不能从“印度化”等国家名称直接认定具体语言、地区或所有人物外貌。
- 复用项目中已明确的选择。缺项不影响的原片盘点与方案比较可以先做；进入依赖缺项的资产或台词定稿前再补问。讨论候选不等于已采用版本。
- 指认本次使用的真实原片及版本，记录文件位置/资源身份、指纹、时长、画幅、帧率或时间戳。读取对应剧本、字幕、音轨和已有资产；已生成成片与尚未生成的导演候选稿分别记录，以实际选定原片为转绘依据。
- 只有剧本时可准备本土化方案，注明尚缺运动原片；只有视频时先观察、转写和校正。无法辨认的台词或动作标为待核，不凭梗概补成原片事实。保留原件与历史输出，新版本另存。

## 2. 原片逐镜对应与替换表

先按真实切镜建立稳定源镜号，记录源片起止时间码，必要时记录帧号或PTS；源镜头、生成任务和最终剪辑段分别编号。对每镜记录人物、说话人、对白/心声/旁白、动作起终状态、摄影机与切点、场景地理、持物、画面文字和声音节拍。生成任务拆分或合并仍能追溯回源镜区间，不把原片均分成固定时长再填内容。

本土化对照表至少覆盖以下内容；只填写项目实际涉及的项：

| 对象 | 需要记录的对应关系 | 保留与检查重点 |
|---|---|---|
| 人物与服装 | 原人物稳定ID、目标版本ID、姓名/称谓、年龄关系、身份、外貌、服装、声音 | 性格、地位、动机、关系与表演弧线；新衣装支持原动作、抓握及遮挡 |
| 场景 | 原地点与视图、目标地点与母版、地标/门窗/家具对应 | 空间功能、进出路线、可走通道、轴线、人物距离与光线来源 |
| 台词与术语 | 原句ID及时间码、原文、目标文本、说话人、声音类型、术语/称谓表 | 信息、意图、语气、已知事实与悬念；目标语言试读时长与口型需求 |
| 道具与文字 | 原物件ID、目标形制/文字、尺寸、持有者、握持点、叙事作用 | 文化替换后仍能完成原动作，保留关键数字、线索、价值关系和使用结果 |

只替换本轮指定对象；合适的自然环境或通用物件可以复用。新道具不因本土化改变持手、数量、尺度、重量表现或接触关系。场景母版先适配原片调度，再落实当地建筑与陈设；不能因参考图更漂亮而堵住原来的退路或改变相对位置。

地方制度、称谓、建筑、礼仪和道具形制需要真实依据时核查相应可靠来源；架空设定标为创作候选。人名、机构、服装和场景形成同一套背景，避免把不同地区与时代的符号随意拼接。世界观术语可以本土表达，能力规则、关键数字、事件因果和悬念保持对应；宗教映射、葬仪、币值或礼节调整若会改变原剧情/动作，列为具体待决项，不自动套用。

## 3. 统一目标资产与代表性样段

沿[图片制作规范](image-production-standard.md)盘点并准备人物/造型、场景与所需视图、关键道具、色卡及画面文字样式。各目标资产保留稳定身份、真实版本和采用依据；同一角色或地点跨镜复用，同一项目的不同国家/语言版本分别登记。更换国别不自动更换画风、演员年龄或关系。

先在本轮授权内选择能代表主要难点的短段验证：例如人物近景、目标语言对白与心声、多人互动、转头/遮挡、持物、走位及换场。段落和数量服从原片，不把示例固定成通用片长。先看实际结果再扩大制作；失败定位到身份、空间、动作、语音或执行能力，保留有效部分局部返修。样段授权按当前范围执行，不自动扩成整集或额外候选批次。

## 4. 目标语言、配音与口型

- 按原句的事实、意图、人物关系、情绪与信息揭示顺序写目标台词，形成原文/目标文对照及统一术语表。让目标人物自然说话，同时保留剧情信息；不添加新身世、能力或读心触发条件。
- 按源镜发声窗口试读或试听，记录目标语言实际时长、重音、呼吸及必要反应。先通过自然措辞与声画覆盖适配；无法在原窗口自然表达时列出具体冲突和调整方案，不靠极端加速、吞句尾或改变剧情硬塞。
- 每个目标角色沿用已选声音。对白、心声、旁白分别排时间；心声保留原片闭口或对应表演，不变成出声对白。配音与口型由当前可用能力执行，之后核对实际发音、语气、音色和视听同步。
- 优先使用已有对白/环境/音乐分轨。混合原声需替换台词时，先核实可用的人声处理能力并试听；保留可用环境与动作声，避免原语言人声残留或整轨静音造成空洞。不把通用视频编辑当作自动保原声或自动配好目标语言的保证。
- 替换项目范围内的字幕、介绍牌、系统UI、标牌、书信与屏幕文字。重要数字、倒计时、问号和线索逐项核对。目标文字字体、排版、字形连接与阅读时长需看实际渲染；现有中文字幕脚本不自动证明支持全部目标语言。保留无字母版、字幕文件和可独立调整的文字层。

## 5. 按原镜转绘与参考职责

在项目已选渠道核对当前模型的真实输入契约：是否支持源视频编辑/运动参考、所需资产引用、输入输出时长与音频控制。使用适配的入口，不把图片生成、视频编辑或普通参考生成混为同一种保真能力。平台不可用或缺少必要能力时说明实际缺口，继续可完成的设计与准备；未经选择不换渠道。

提示词沿[视频提示词规范](video-prompt-standard.md)，结合本模式写明：

1. **源片职责**：精确源节点/文件与区间，控制原动作、表演节拍、构图、机位、运镜、镜序及切点。
2. **目标资产职责**：真实人物、服装、场景、道具与声音引用分别控制目标身份和本土化外观；源片中的旧面孔、旧衣装与旧建筑不承担目标身份参考。
3. **替换清单与保留项**：本段具体换什么，保留什么动作关系、持物手、光线、声音类型与关键剧情信息；明确遮挡、反射、背景人物及文字的相关替换范围。
4. **逐镜执行与首尾接口**：按源片观察到的节拍交织写人物动作、反应及对应摄影，加入目标语言台词和实际时槽；不让源片参考取代完整执行正文。

按原片切点和实际模型能力分段；同镜不得因任务分段出现重复动作、瞬移或新切镜。需要真实前段结果的续接保留依赖，普通可独立段落按共享目标资产执行后检查切口。源片既有转场保留其作用与节奏，任务边界本身不成为新增动画、黑场、慢动作或空等的理由。

单帧外观通过后还要看整段身份、纹理、光色、背景和道具的时间稳定性；不将各帧独立出图默认当作已经解决视频转绘。不承诺仅凭提示词就能逐帧保留原片。

## 6. 对照审查、合片与跨集继承

把源片与本土化结果按源镜区间对齐，原速播放、试听，并在动作接触点、口型、遮挡和切口抽帧。检查：

- 剧情因果、知识状态、关系、悬念与表演变化是否对应；人物反应仍由同一刺激引发。
- 目标身份/服装/声音是否跨镜稳定；原人物、原建筑、原语言和应替换的文化元素是否残留。
- 新场景是否支撑原走位，轴线、出入口、视线与光向是否连贯；手、身体支撑、碰撞与持物是否成立。
- 目标台词含义与术语是否准确，语速、呼吸、句尾和反应时间是否自然；心声口型、配音同步及文字可读性是否正确。
- 原片镜序、动作节奏、切点及声音承接是否保留；规格、完整解码、真实帧数/时间戳和交付文件是否对应。

按[剪辑与成片验收](post-production-standard.md)合片，区分画面切点与声音切点。回忆优先复用本土化版本已经完成的真实镜头；跨集保留同一套角色、声音、场景、道具、术语和实际首尾状态，不能回扣到未替换的原片人物。局部问题回到对应镜段修复，旧版本与回执保留。

## 7. 接入现有管线与项目产物

复用[制作流程与并发](production-workflow.md)和现有调度、恢复、交付入口。本模式新增的是制作方法，不表示脚本或平台已自动支持转绘、翻译、配音、口型或文化验收。

项目保存原片及版本依据、本土化对照表、目标语言台词与术语表、已采用目标资产、原镜对应的转绘导演稿与提示词、任务回执、对照审查和剪辑/交付记录。国家、人名和示例设定留在项目中，公共 Skill 只维护通用方法。

使用现有 `director_contract` 时，`inputs.script`绑定本次目标语言台词稿，`inputs.design`绑定按源片观察整理的转绘导演稿，均计算真实指纹；原文及源镜区间另存对照。`cast`使用目标角色规范名，`dialogue_source`与事件文本使用同版目标语言，保留原句ID对应，不能为通过原句校验覆盖中文原稿。详见[脚本与数据约定](automation.md)。

站位图记录源片实际调度与替换后可执行空间。相邻任务仍记录两端接口；沿用源片普通硬切时，`director_contract.requirements.transition_animation`可显式设为`false`，不为满足新拍镜头的默认动画要求而添加转场。需要重构的局部设计和已接受任务的恢复分别处理，旧任务沿原键与快照回读。

成功生成、技术检查、内容审查、用户采用、聊天展示和画布同步分别记录。按本轮授权和已选审核方式推进；学习/安装本规范不授权真实付费生成。
