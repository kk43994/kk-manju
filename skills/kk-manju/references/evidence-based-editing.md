# 以真实素材为依据的叙事精剪与开源工具

用于素材已可用、需要提高剪辑表达、多人多版本选段、配乐接缝或多集合篇的任务。承接 [后期规范](post-production-standard.md) 和 [CapCut 分轨工程](capcut-editing.md)。按具体问题启用工具，不要求所有项目安装全部仓库。

## 剪辑先回答的问题

先看一场戏中的信息、情绪和行动怎样改变，再细调每个切点。对待修段写清：观众此刻知道什么、接下来想看什么、该看谁的反应、哪个动作或声音推动切镜。不要将「有声音就留、没声音就删」用作叙事规则，也不要规定所有镜头两秒一切。

节奏分三层：整场是否推进因果；场内揭示、回应、行动是否重复；单镜是否留下有意义的呼吸/反应。长镜可以承载连续事件，短镜可以停住情绪。先解决重复揭示和生成余量混进正文，再考虑压缩必要表演。

## 从整条生成片拆到可用的小镜头

1. 建立素材索引：原文件、指纹、版本、实际镜内切点、对白区间、可用动作和缺陷。检测出的镜头只是候选边界，明暗变化和快速运动也可能误报。
2. 按叙事任务找区间：例如「递盒接触」「听到威胁的反应」「人物已经站稳」，不能仅按文件名或提示词找素材。
3. 粗定位后密集抽查边界，并正常速度回看前后。记录源时间，不从缩略图猜一段已完成的动作。
4. 为每个 CUT 说明入点/出点的可见依据。对白和画面可以取不同区间、不同版本；不为更换画面重新配音，不为多用版本重复剧情。
5. 相邻镜检查动作相位、持物手、视线、轴线、人数与关注点。故事板有设计但回片没拍到时，不按设计文字宣称已实现。

方法借鉴 [DirectorX 的素材区间定位与密集帧细调](https://github.com/savebees/DirectorX/blob/main/directorx/services/grounding.py)。采用其证据对应方法，不直接运行其外部付费模型，不套用解说视频的旁白覆盖率、全片旁白或固定节拍。

## 声音不随每条视频重新开始

把「视频自带混合音轨」与「独立对白、环境/动作、配乐」分清。音视频分离仅抽出混合音轨；人声提取通常不能满足保留环境声的要求。用户只要去 BGM 时，目标是保留 dialogue + effects/ambience。

- 原本没有明显配乐的片段优先保留原声，不机械重跑全片。
- 有配乐的混合音轨先做代表性 A/B 试验：对白叠音乐、无对白动作、长环境尾音。保留原音频与分离输出，不覆盖。
- 可用 [Bandit v2](https://github.com/kwatcharasupat/bandit-v2) 的 speech/music/effects 模型，或 [ELUATE](https://github.com/anaxoniclabs/ELUATE) 的执行封装；不能将二分离的「伴奏」直接当成音乐轨。
- 逐段听原声、对白+音效、移除残差。残差中若出现可辨字音、脚步、碰撞或重要风声，应回退该段或补回真实声源；不要把所有残差叫作纯音乐。
- ASR 用来发现失字与时间偏移，波形/转写相近不能证明音色和效果无损。无干净真值时不要虚报分离质量分数。
- 对白保留完整表演与必要呼吸；环境底声跨同场切点持续，动作点音与接触同步；J/L-cut 允许声音与画面采用不同边界。
- 统一配乐按场次/情绪段落连续铺设，切镜不自动重启音乐。先定进入、发展、退出和有意抽空位置；对白时适度压低，退出保留音乐尾音。多个音乐段按情绪和乐句交接，不能以一条循环曲强盖所有情节。
- 后续需要统一后期配乐的项目，视频提示词写明「生成对白与现场声，不生成背景配乐」，音频仍开启；这是源头约束，回片仍需检查是否遵守。

权重与代码分开记录：Bandit v2 官方权重 [Zenodo 12701995](https://zenodo.org/records/12701995) 标为 CC-BY-SA-4.0；ELUATE 代码 MIT，Bandit v2 代码 Apache-2.0。保留来源及版本，复制或发布对应代码/权重时遵循其条款，不将代码许可证冒充权重许可证。

## 整片处理后的二次核查

- 配乐不能只按整条或整段平均响度决定增益。先检查对白附近的短时 RMS 与峰值；低平均值但局部突出的音乐可能被整体放大后盖住人声。统一配乐总线可用前视、快压低/慢恢复控制，保持对白与环境轨原有时序；记录处理前后的局部证据，不因算法数值就宣称试听通过。
- 整片 ASR 与分离音轨 ASR 的分句、简繁体和 VAD 边界可能不同。用词级时间窗定位疑点，再对同一短区间关闭 VAD 复查；整片少识别一句不等于素材真的丢字，反之能识别也不代表音色无损。
- 声画统一使用全局帧边界；不要把每条视频时长分别向上取整后累计。云草稿的整数毫秒与本地帧号分别记录并核对最终实际解码时长。
- 单独对白、环境声与配乐文件在输入清单声明 `media_role=audio`，其余默认为 `video`。编译器必须核对所有采用视频都进入画面、所有独立音频都进入声音、指纹未变；不得为了加声轨放宽对遗漏/偷换画面的检查。
- 如复用已审转场的短合成窗口，记录上下游原镜号、原主片帧号及转场类型；明确该窗口已烘焙，其他源片继续独立可剪。整片分离所得长声源可按镜段分割编辑，但分割处保持等时连续、不自动加淡入淡出。

## 合篇按连续剧情重剪

读取每集最后和下一集最初的真实画声。去掉仅用于分集收尾的黑场、重复起手和重复建立，但保留必要时间变化及台词。相邻集若已共享同一动作，不再强加转场；先匹配手部/视线/动势，再处理连续声音。确有空间或因果缺口时才设计补镜，沿项目模型/预算权限提交。

合篇保留原有集数与 CUT 映射，独立生成剪辑版本，不覆盖单集人工微调。原片烧入的剧情文字与后期对白字幕分别处理。

## 当前可调用的开源组件

| 组件 | 具体用途 | 不能据此宣称 |
|---|---|---|
| [PySceneDetect](https://github.com/Breakthrough/PySceneDetect)，BSD-3-Clause | 定位源片内部切镜、缩小闪帧审查范围 | 自动懂剧情、检测点都是正确切点 |
| [faster-whisper](https://github.com/SYSTRAN/faster-whisper)，MIT | 复用本地 ASR，定位字音和停顿 | 自动识别文本就是原剧本；没对白就是废镜 |
| Bandit v2 / ELUATE | 可选的去配乐候选生成，保留对白和音效估计轨 | 无损恢复、自动通过听觉验收 |
| [OpenTimelineIO](https://github.com/AcademySoftwareFoundation/OpenTimelineIO)，Apache-2.0 | 保存源区间、项目时间、重叠声轨与来源的可交换备份 | CapCut 已导入、滤镜/字幕/混音已完整渲染 |
| DirectorX 的区间证据方法 | 叙事意图 → 候选区间 → 密集帧修边界 → 看片复查 | 引入整套应用或它的外部服务已获付费授权 |

[auto-editor](https://github.com/WyattBlue/auto-editor) 的自动停顿裁剪适合部分口播，不作为对白剧默认剪法。[stable-ts](https://github.com/jianfch/stable-ts) 已于 2026-05-30 归档；有词级强制对齐需求时可另评估固定版本，不为重复现有 ASR 功能强行加入。仓库状态按实际使用时复核。

## 已提供的脚本

隔离环境中安装所需依赖，固定本次实际版本；不要运行来源不明的安装脚本。首次试用不接入全项目批处理。新增实验脚本当前可直接运行并写本地回执，尚未注册到自动更新版 companion 的白名单，不宣称已出现在面板；已登记制作脚本仍走 companion 入口。

```sh
# 按实际环境填写 python 路径。
python scripts/editorial_index.py index --plan edit-plan.json --input input.json --out internal-shots.json
python scripts/editorial_index.py otio --plan edit-plan.json --input input.json --out edit.otio
python scripts/music_removal_trial.py source.mp4 --checkpoint checkpoint-multi.ckpt --start 0 --duration 12 --device mps --out audio-trial-r1
```

`editorial_index.py` 读取现有 CapCut plan，不改剪辑决策。index 校验素材指纹；otio 把重叠声音分到不同轨，回读核对源入点、时长、成片入点；字幕、效果与音量参数保留为元数据，仍由原 CapCut 编译器执行。OTIO 不自动上传或迁移编辑器。

`music_removal_trial.py` 验证官方 multilingual 权重 SHA-256，以 batch_size=1 生成不超过 30 秒的可回退候选；保留原混合音、speech、effects、两者相加和移除残差。输出长度一致才继续，默认不增益放大；仅防溢出时统一衰减。`quality_review` 未完成与 `adopted=false` 必须保留到真实听审，不把进程成功当自动采用。

本次测试环境版本记录于项目；可用组合：ELUATE 0.0.3、PySceneDetect 0.7.3、OpenTimelineIO 0.18.1、faster-whisper 1.2.1。模型权重独立缓存，不打进 Skill 安装包。

## 精剪交付检查

技术检查、画面自审、听觉自审、用户采用分别记录。至少检查：剧情因果/重复信息；相邻景别和关注点；听者反应时机；动作接触与声效；同场底声；配乐是否在无叙事理由时截断；对白首尾；字幕；完整解码与声画同步。保留可编辑多轨工程、来源/源时间、音乐来源与独立试听片。
